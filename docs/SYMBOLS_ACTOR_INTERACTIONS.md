# Actor interaction and scripted locomotion candidates

Static File #1 US research, 2026-11-04. Original image identities are in
[the central index](FUNCTION_INDEX.md). The action-one table relationships are
in [actor states](SYMBOLS_ACTOR_STATES.md), and alignment/shared request helpers
are in [actor actions](SYMBOLS_ACTOR_ACTIONS.md). No game launch, attachment,
build, replay or live-memory inspection was performed.

Actor action byte+8, substate+9, phase+A and selector/secondary phase+B are
separate fields. Hexadecimal state labels are evidence keys; original gameplay
enums and animation names remain unknown. Motion selection0x5D4CF0 can remap
codes using actor resource/state; requested codes below do not imply one fixed
asset for every actor.
