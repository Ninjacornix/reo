The [pinned Code Veronica comparison](recvx-crosscheck/AUDIO_SECOND_PASS.md) corrected this note's former final-loop-offset base18 claim. Original t5 advances base4->6->8->C->10;126C5C adds the input pointer, and126CCC reads4(t5), giving base14. This matches CVX and Outbreak's own fourth loop-word writer. The version-dependent base and minimum-length differences remain; no all-input encoder/decoder parity is asserted.

The caller1249E8 ignores the return values of loop and AINF extraction after its required base/history setup. Default-zero/partially written metadata must therefore remain distinguishable from validated loop or AINF presence. These parsers use sign-extended declared offsets and minimum fixed lengths; they do not establish a universal safe header format or native path reachability.
