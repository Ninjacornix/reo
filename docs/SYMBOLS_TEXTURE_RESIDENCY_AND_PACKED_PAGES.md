[Texture transfer packet construction](SYMBOLS_TEXTURE_TRANSFER_PACKETS.md) and [graphics residency controllers](SYMBOLS_RENDER_STATE_CONTROLLER.md) establish the delegated paths.19D730 is called by [render preparation](SYMBOLS_RESOURCE_RELOCATION.md) when texture dependencies exist; already resident records skip allocation/conversion. Its unbounded retry is a candidate investigation boundary, not evidence that the user's incident entered it.

The packed-page routines stage8192 bytes on the stack and use source pitch implied by rounded page columns. Replacing them with a linear copy would discard the owned nibble/tile permutation. Correctness requires padded extents,format identity and byte-for-byte offline comparison before any native change. Mapping these routines does not establish that conversion repeats per draw.
