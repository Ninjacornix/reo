## Important boundaries

Normal helpers0x370640/6D0 test length only **after** normalization. They cannot
be used as evidence that degenerate triangles are guarded. XY helper0x370490
also reads a third float from each input; translating the interface to an
8-byte host point changes its memory-read contract unless separately justified.

The four angle-to-matrix adapters differ in composition versus basis reset and
XYZ versus ZYX order. Parent/child rendering paths rely on those differences;
merging all four into one guessed Euler helper would lose behavior.
