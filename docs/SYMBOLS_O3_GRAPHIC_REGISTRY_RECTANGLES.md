The image-loader count check compares a signed byte to128, which is outside its representable range. This is a static capacity-guard mismatch. The reviewed asset-group helper requests only one or two images per invocation; an actual execution path accumulating128 loads has not been established. The neighboring handle getter and cleanup also read the count as signed. This observation is separate from any reported slowdown and does not justify a runtime patch without reachability and behavior checks.
