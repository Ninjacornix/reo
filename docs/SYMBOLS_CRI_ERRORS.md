# CRI error callbacks and shared text contracts

Static File #1 US research, 2026-11-04. Identity checks: [central index](FUNCTION_INDEX.md). No game, build, replay or attachment was run.

The high-connectivity helper0x1280D0 publishes error text. Its numerous ADXF/ADXT callers do not make it a lock, file-read worker or decoder. Error callbacks run synchronously and do not necessarily abort their callers. Multiple layers use shared text and callback globals; preserve reentrancy and mutation behavior before optimizing or redirecting them.
