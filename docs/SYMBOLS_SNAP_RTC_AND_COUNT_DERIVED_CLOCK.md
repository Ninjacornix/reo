Static File #1 US research, 2026-11-04. Complete owned main-ELF instruction intervals, with identity in the [central index](FUNCTION_INDEX.md). This is the clock used by [network polling and retries](SYMBOLS_SNAP_CONTEXT_LIFECYCLE_AND_RETRY_QUEUES.md). No clock was sampled from a running game, and no update speed was changed.

The seed calculation is retained literally: `(year-1970)*365`, plus `(year-1973)>>2` when year>=1973, plus monthOffset[month-1] and day, plus one if year divisible by4 and month>=3. It then multiplies through24/60/60 and adds hour/minute/second. It does not subtract1 from the day in this body, validate BCD nibbles/calendar fields, handle full Gregorian century rules or apply an explicit time-zone correction. POSIX epoch compatibility is therefore not claimed.

Owned table2580B8 consists of twelve unsigned words, decimal `[0,31,59,90,120,151,181,212,243,273,304,334]`;48-byte SHA-256 `3f1431b31172b4be5418bda2f4063f512f2f7a7cfdce81a60b131792b5f7f694`. Every element and the complete span were checked. Invalid month indexing is not locally rejected.

Count comparison chooses the wrapping subtraction path when current<=previous; that path adds2^32 before truncating accumulated ticks to32 bits. The exact threshold tests are strictly greater than300 and1000000. Equal boundary values remain unnormalized until another call changes them. No host clock frequency, pacing accuracy or pause behavior follows solely from the encoded300 divisor; those need separate runtime evidence.

Sleep uses a single shared semaphore-id word. Concurrent/reentrant calls or outstanding alarms require an ownership proof; this body does not provide one. The helper's constants are encoded alarm units, while its requested fraction is converted from nanoseconds to the clock's microsecond-style field. No standard sleep precision, interruption semantics or observed hang is claimed.

Owned diagnostics:2580E8=`Error getting RTC: %d\n`;258100=`TOY clock: %04d-%02d-%02d %02d:%02d:%02d GMT\n`;258130=`Timeval: %d.%06d\n`;258148=`Wait 5 seconds\n`;258158=`Wait .5 seconds\n`. A diagnostic label naming GMT does not add a time-zone correction absent from the actual seed arithmetic.
