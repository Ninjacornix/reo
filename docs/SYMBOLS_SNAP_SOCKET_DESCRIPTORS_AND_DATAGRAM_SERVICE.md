# SNAP socket descriptors and datagram service

Static File #1 US research, 2026-11-04. Complete owned main-ELF intervals; identity in the [central index](FUNCTION_INDEX.md). Extends [SNiop TCP/DNS adapters](SYMBOLS_SNIOP_SOCKET_AND_DNS_ADAPTERS.md), [datagram RPCs](SYMBOLS_SNIOP_DATAGRAM_AND_AUXILIARY_RPC.md), [packet ownership](SYMBOLS_SNAP_PACKET_LISTS_AND_POOL_ALLOCATION.md) and [context polling](SYMBOLS_NETWORK_PLATFORM_WORKER_AND_POLL.md). No socket, game, replay, attachment or test was run.

The logical descriptor bank has64 records of36 bytes, based at pointer GP-7FD8. Record0 is signed16 backend endpoint,2 unsigned16 type (1 TCP-shaped,2 UDP),4 unsigned16 state,8 embedded received-packet list,1C/20 address/port metadata. State names below stay numeric where the original enum is unknown. GP261CF0 resolves pool pointer GP-7FD4 to259D1C. Addresses/offsets/states are hexadecimal; counts explicitly called decimal retain that meaning.

Most public wrappers clear the libc errno word before their own admission. Returned descriptor index and backend endpoint id are separate identities. Pointer lookup validates index0..63 but not whether that slot is occupied.

The datagram pump resolves two previously opaque packet fields:10 stores a source address and1C a source port in this queue. Those same offsets participate in other packet metadata/retry contracts; field names must retain the owning context instead of forcing one universal meaning.

The readiness scan's clamp resolves the earlier fixed fd-set range question for admitted logical descriptors. Context polling's nfds=descriptor+10 cannot extend this scan beyond64. It still ignores the timeout argument and can synchronously drain backend datagrams through the RPC pump; duration and producer rates require later measurement.

Owned diagnostics:258068=`UDP Handle: %x \n`,258080=`Pool allocation failure, %d\n`,2580A0=`Enqueue failure, %d\n`. Source status conversions, type gate anomalies and ignored capacities are recorded literally. No delivery failure, uninitialized-data exposure, overflow, deadlock or slowdown was reproduced.
