Continues [large-integer block adapters](SYMBOLS_DNAS_BIGINT_BLOCKS.md). No game, build, replay, network request, live-memory read, attachment or benchmark occurred.

Objects have **capacity+0, used limbs+4, limb pointer+8**, with64-bit limbs least significant first. Arithmetic is unsigned magnitude; status109 indicates local subtraction borrow/range failure. Functions generally assume admitted storage and counts, and an initialized zero commonly retains one zero limb. Alias safety and all arbitrary integer inputs have not been proved. Preserve-growth and discard-growth helpers have different contracts; both can destroy the old allocation on allocation failure.
