# Single-player overlay: actor actions and off-room movement

Static File #1 US research, 2026-11-04. Catalogue partition **o9**, runtime id **9**, load base **0x810000**, owned MWo3 `single.bin`. This closes the action-execution layer adjacent to [room navigation](SYMBOLS_SINGLE_NAVIGATION.md). Proposed names identify entry behavior, not recovered original symbols or translated replacement code. No game, build, replay, network session, live-memory read, attachment or benchmark occurred.

Actor halfword **+FF8** selects a high-level local action; **+FFA** remembers its previous value. Four bytes **+1008..100B** are action-local substates. The low byte of navigation action **+1054** selects one of 14 waypoint handlers, while its upper byte often identifies a room condition. Actor byte **+54F** is a dynamic state/code: 0x81C1A0 synthesizes it for off-room execution. Its values must not be assumed to be character ids or permanent actor types. Byte **+103A** holds a transition lock. Word masks **+F78/+F80**, analog-like halfwords **+F98/+F9A**, and bytes **+FF2/+FF3** form generated actor-control state. Physical button names remain unconfirmed.

Owned data verifies the 11-entry callback table at **0x8296E0**, its 14-entry waypoint table at **0x829710**, and the parallel off-room table at **0x829750**. High-level state 2 selects waypoint dispatch in the first table and timed discrete movement in the second. There are zero words after these spans; neither dispatcher bounds its index locally. Treat these as admitted domains, not proof arbitrary values are safe.
