# DNAS overlay: large integers and fixed-size numeric blocks

Static File #1 US research, 2026-11-04. Catalogue **o5**, runtime MWo3 id **7**, base **0x6E0000**, owned `insdnas.bin`, SHA-256 **97174f5d367cd90bedd5ba397c6492e9fb4bbd0ec7d6021c2be524c49925d38e**. No game, build, replay, network request, live-memory read, attachment or benchmark occurred.

The twelve-byte large-integer record has **allocated limb capacity +0, used limb count +4, limb pointer +8**. Limbs are 64-bit words, least significant first. Byte import/export reverses limb/byte order to a big-endian external representation. This strongly supports large unsigned integer arithmetic. It does not yet identify all arithmetic entry points or prove the fixed-block callback implements a particular RSA variant.

The numeric-block state at0x6F95F0 contains block byte count **+0**, scratch pointer **+4**, accumulated byte count **+8**, two large integers **+C/+18**, and an operation callback read from **+24** by0x6F98E0. The first large integer supplies output block length; the second is rejected when equal to1. A modulus/exponent interpretation is probable from use. Following constructor6E7B60 now establishes default callback6EEC48, documented in [numeric providers](SYMBOLS_DNAS_NUMERIC_PROVIDERS.md); custom callback identity and full arithmetic equivalence remain separate questions.
