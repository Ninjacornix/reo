## Overwrite loops and limits

The local overwrite expression calls74AA20, converts the returned word to float, divides by float bits4EFFFFFF, multiplies by256 and converts to integer with an explicit >=2^31 correction before storing the low byte. It is observed deterministic LCG-derived overwrite, not a security or entropy guarantee. The request builder overwrites four groups of four stack bytes. The send facade overwrites exactly0x400 prefix bytes, **0x8033** body bytes and **0x8433** joined bytes on the relevant paths. The latter two loops use `counter > lastIndex` after increment with limits0x8032/0x8432, so their counts include the last indexed byte; they are not silently rounded to nearby allocation sizes.

After successful provider count equality, the facade overwrites the joined buffer and returns that count without invoking failure cleanup slot7616D0. On a negative initial assembly result it exits before provider calls/buffer cleanup, preserving that result. A positive busy query exits -601 before those provider calls.
