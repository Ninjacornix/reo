Complete original intervals, all12 owned vtable words228C60, identifier23DA78, SJUNI Error literal and hexadecimal digit table229898 reviewed. No queue, decoder, game or build executed.

SJUNI keeps four lists of borrowed `{pointer,length}` spans and a free list of16-byte nodes. It differs from SJRB's byte-capacity ring: getting a complete span returns its node to the free list, while payload storage stays owned by the caller. Mode byte5==1 permits splitting and merging adjacent spans. This is a source contract, not a proposed replacement implementation.
