Both chunk handlers start nextChunk=2F2hex, then compare unsigned(offset+limit) against advertised size and bank capacity. End-of-size takes precedence; remaining length is low16(size-offset), otherwise low16(bankCapacity-offset). In-range continuation stores offset+limit. On terminal group advance,1F56D0 clears selector/offset and selects8;1F5C20 selects12 without an equivalent unconditional second reset. The decode call uses the original returned group/offset even after global next-group state advances.

Input mismatch does not guard indexed size loads or destination arithmetic. Count clamp in secondary enumeration does not itself constrain a mismatched later returned group. Original stream/frame and caller-side admission remain required.
