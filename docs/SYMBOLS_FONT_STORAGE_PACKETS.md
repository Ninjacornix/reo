Glyph preparation runs before foreground/shadow packet emissions in the default string renderer; the two packet emissions do not imply two bitmap decompressions. The distinction between descriptor-selected direct pointers, CPU-expanded workspaces and DMA references matters for future profiling and lifetime-safe replacement. None of these static mappings measures a texture upload or confirms a slowdown cause.

The separately reviewed o2 body6DE800 is a timed status/message text renderer, not a cache-flush or queue routine. See [timed-message resource flow](SYMBOLS_TIMED_MESSAGE_RESOURCE_FLOW.md). The external binding still must matcho2 before inheriting that contract; the parent owns font selection/end-tag handling.
