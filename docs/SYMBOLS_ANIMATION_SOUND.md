## SDR command queue

The resident queue has 32 records of 12 bytes at0x2B0A80, write index0x2B0A68 and read index0x2B0A70. A negative first word marks a free record. Producers below trust queue indices and have no local mutex; the consuming/sending path and its semaphore must be considered before changing publication or scheduling.

The frame gate retains wrap and global clock-mode semantics. Replacing repeated animation calls with one global callback would need proof that event windows, random draws and actor-specific sound scheduling remain equivalent. Spatial attenuation currently touches renderer parameter1A; caching or moving it across render state changes needs an explicit lifetime contract.
