A zero/negative signed dimension executes no edge samples and returns1 on admitted direction; this does not establish that real assets use such dimensions.

Height conversion has two separate operations: the guest floating conversion to integer, then signed integer division by decimal50, then often truncation to signed8. It is not a mathematical floor across arbitrary negative inputs.6B07B0 checks unconverted floating coordinates against grid limits, then callers may reuse already-written converted integer words. Original FPU conversion semantics must be preserved in any reconstruction.

Several narrow admission gaps are recorded without a runtime diagnosis:6AF9E0 ignores failed slot resolution and admits unsignedFF into slot31;6B0890 can retain layer-1 if a height is absent from0/2/4/6;6B0AC0 assumes nonnull output and a successful object lookup on its status1 path;6B1010 has no slot&1F mask.
