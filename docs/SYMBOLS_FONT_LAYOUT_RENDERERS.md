Prepared-bitmap text rendering is separate from per-glyph raster expansion and byte-oriented font rendering. Width conventions, punctuation offsets, shadow color masks and count checks differ between paths; merging them based only on a shared helper name would lose original behavior. Actual installed handler identity must also be established because the current override source substitutes several packet helpers.
