Record size comes from an unsigned byte. The alignment branch's negative arm is unreachable for that byte value; the admitted positive path rounds it to a multiple of4, then subtracts12. Short values can become a negative copy length before the cursor child, and configured slot payload size independently determines the later fixed copy. Producer format/size invariants must be proved before diagnosing malformed input.

Sorting is deferred until pop needs an ordered head. It sorts pointers, then changes intrusive links; it does not move payload blocks. No invocation rate, per-frame cost or claim that this path executed during offline play follows from the static map.
