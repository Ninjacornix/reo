The cache is eight entries of308 bytes and the TCP adapter has three slots; those bounds come from full loops and layout arithmetic, not a count of callers. Cache hits compare bounded strings and return mutable shared storage. Neither that cache nor its polling cadence is the gameplay clock.

The read/write wrappers have distinct contracts: receive returns the child byte count after narrowing; send returns the original request whenever its child is nonnegative. A zero/negative signed16 send request also reaches the already documented child early-return path whose lock release is partial. These are concrete static investigation boundaries. Valid request ranges, path reachability and incident contribution must be established before proposing a fix.

Literal constant-only entries1D97E0,1DA310 and1DA320 remain in separate mechanical classifications; no subsystem role is invented for them. No game speed, worker policy or runtime behavior was changed.
