# Main kernel alarm, signed-slot and DECI2 purpose refinements

Static File #1 US research, 2026-11-05. Owned main ELF `SLUS_207.65`, SHA-256 `06bd5fd7243144cd30cdd0c0023763a369738cb91b177b35e85f6a4782b4ca46`. Sixteen complete original entries, supporting copied alarm-code bytes, patch tables, indexed callers and aligned literal-pointer/J/JAL patterns were checked. No game, guest instruction, build, target process, kernel service or attachment ran. Public reference retrieval was read-only and pinned below. The catalogue denominator is unchanged.

These refinements extend [the original kernel notebook](SYMBOLS_KERNEL.md) and [DECI2 TTY notebook](SYMBOLS_DECI2_TTY_IO_AND_COMPLETION.md). They add **nine supported purpose candidates** and preserve **seven unresolved purposes** separately. A descriptive API-family candidate does not imply a native implementation, successful runtime use or compatibility across kernel revisions. The wrapper instructions and signed selectors are confirmed independently of the proposed API identities.

Reproduce with [review_main_kernel_deci2_purpose.py](../tools/function_index/review_main_kernel_deci2_purpose.py). The [private receipt](../build-function-index/proxy-main-kernel-deci2-purpose-review.json) retains all16 complete word listings/hashes,90 original source-comment words,10 omitted zero delay-slot words, reference identities and complete alarm support listings. It also verifies that all16 have zero indexed callers and zero aligned literal-pointer/directJ/JAL patterns in file-backed main load segments and all hash-bound owned overlays. This does not exclude constructed pointers, kernel-side use or dynamic code. The optional `--fetch-references` fetches only the exact public source revisions and verifies their hashes; default operation is offline.

## Owned alarm metadata overrides modern-number assumptions

11DDE8 copies source20AC40..20B380 to80076000..80076740, installs a lookup service, then resolves/reinstalls six selectors from the owned20B3A8 registration list. The complete lookup20AC40..20AC78 walks six pairs at runtime80076710, which corresponds exactly to source **20B350** under this copy. Its actual pairs are:

| Selector | Copied target | Original source address | Supported role |
| --- | --- | --- | --- |
|FC andFE |80076440 |20B080 |16-bit time/callback/common alarm insertion wrapper. |
|FD andFF |800762A0 |20AEE0 |Search and remove alarm record by ID. |
|12C |80076488 |20B0C8 |Timer interrupt handler, unchanged context from the earlier patch notebook; no additional mapping credit here. |
|8 |800766C0 |20B300 |Interrupt-dispatch continuation, unchanged context; no additional mapping credit. |

Complete20B080..20B0A0 masksa0 withFFFF, calls copied80076160, performs sync and returns its result. Complete insertion helper source20ADA0..20AEE0 uses the timer counterB0001800, a64-slot admission, an ID bitmap, sorted20-byte records with callback/common/savedGP and the timer compare setter. Complete removal source20AEE0..20B080 searches active20-byte records' word+4 for the caller ID; on match it removes/shifts records, clears the corresponding ID bit, updates the timer when required and returns a computed remaining-time difference. Missing entries return-1. These complete original byte listings are retained in the receipt; no copied payload was loaded or invoked and no extra standalone catalogue mappings are admitted for the support carriers.

The old pinned PS2SDK [alarm table](https://github.com/ps2dev/ps2sdk/blob/af212628b7a3b4f7197675c7236d6bec849c883b/ee/kernel/src/srcfile/src/srcfile.c) groupsFC/FD as SetAlarm andFE/FF as ReleaseAlarm. The owned game instead groupsFC/FE andFD/FF. This concrete difference is why +FD and-FE must be identified from the owned table and handler bodies rather than copying modern names by numeric selector. [Earlier timer patch evidence](SYMBOLS_EE_TIMER_MODE_GATED_KERNEL_PATCH.md) preserves copy sizes, installation gate and source hashes.

For absolute49/53/5A, the separate inference is narrower. The pinned [SDK kernel-mode dispatcher](https://github.com/ps2dev/ps2sdk/blob/af212628b7a3b4f7197675c7236d6bec849c883b/ee/kernel/src/kernel.S) computes an absolute slot before a four-byte table index; the [number declarations](https://github.com/ps2dev/ps2sdk/blob/af212628b7a3b4f7197675c7236d6bec849c883b/ee/kernel/include/syscallnr.h) identify those slot families. That reference explains shared handler selection; it does not prove that an arbitrary sign variant is legal in every trap context. The proposed labels retain the exact sign and qualify API-family purpose. The owned byte-copy11DAF0 installed by [exec argument packing](SYMBOLS_EE_EXEC_ARGUMENT_PACKING_AND_EXIT_BOUNDARIES.md) also prevents an unconditional whole-word-copy claim for-5A.
