## Scene entity preparation and resource bookkeeping

The scene descriptor parser builds pointer views into its input rather than
copying a self-contained scene. Keep the backing resource alive. Preparation
mixes normal actor reuse, temporary actor allocation, enemy allocation and object
path formatting; these operations are distinct from per-frame pose evaluation.

record scanner with a 256-record bound and 0x70 stride. The initializer clears
168 matrix flags while publishing a count of 256. That discrepancy is observable
in the instructions, but prior memory clearing, intended storage size and actual
execution state remain unresolved. It is not yet evidence of the user's hitch.

Host batching or parallelization requires callback/owner lifetime and ordering
analysis; a list walk cannot simply be converted into independent jobs.

also a static optimization candidate, contingent on proving resource identity,
valid byte-sized ids and lifetime. Changing it now would be premature.

Random variant selection changes shared random state. Compiling a reusable
render descriptor must not repeat, hoist or omit that selection without a proved
contract. Child matrix allocation, transform sampling, queue insertion and
callback execution are now separate named boundaries for a future trace.

Audit notes for future implementation: transform samplers initialize three short
angles but copy four halfwords into the child record; the fourth halfword is not
locally initialized. Do not silently infer a zero padding value. The distance
queue adapter similarly copies stack fields beyond the explicitly written
distance. These are input/state admission questions, not newly reproduced bugs.
