The outer actor state byte is **+FFC**, its policy substate **+FFD**, nested task substate **+FFE**, and further phase **+FFF**. Terminal byte FF is a state-machine sentinel, not an elapsed-time marker. Most policy callbacks turn +FFD=FF into outer +FFC=FF and reset +FFD=0. They do not return a consistent boolean result on all paths.

Verified table **0x829E30** contains 28 pointers, grouped as seven categories times four score buckets. At **0x829EA0**, a different table begins: the condition dispatcher at 0x821CD0 indexes it by a numeric condition id. Merging these adjacent arrays would invent policy slots. Target category comes from byte table **0x829D40**, indexed by target record byte +3; the score bucket uses actor character +B98 and thresholds at **0x829DB0**. Target pointer +1068 is based on record index +106E and a 3,472-byte stride from **0x42EB00**; its original type name is unresolved.
