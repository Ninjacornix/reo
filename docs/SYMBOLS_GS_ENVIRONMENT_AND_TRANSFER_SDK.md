## All graphics-path observations and limits

The busy-mask bit order is1 DMA1,2 DMA2,4 VIF1,8 VU-controlvi29,10hex GIF. The wait path tests each initial register state before entering its loop. One counter is retained across all stages; the timeouts are literal guest loop iterations and cannot be converted into milliseconds without measurement. Diagnostic dumps read DMA1 CHCR/TADR/MADR/QWC, DMA2 CHCR/TADR/MADR/QWC, VIF1STAT and GIFSTAT. They report a local polling limit, not a measured root cause in a captured incident.

113010 and113988 start DMA by writing CHCR101hex. Pointer mapping uses `(pointer&70000000)==70000000` to select scratchpad-style high bit, then low0FFFFFFF. Successful local return does not mean the final DMA completed. No native GPU fence, shader compilation, Vulkan pipeline, display refresh or original game-update count is visible in these bodies. Their original MMIO behavior must be separated from the host runtime’s implementation.
