Low-byte and full-word matching are separate contracts. Wildcard selection checks unsigned indices, while some wrappers first check a signed or off-by-one relation. Counting walks both child and sibling links and has no recursion depth guard. Packing retains caller-provided header/padding bytes and uses relative signed16 indices; it is not a validated general-purpose importer for arbitrary input.

The engine caller allocates/constructs resources during model setup. Its existence does not prove this conversion repeats every frame or dominates the recorded slowdown.
