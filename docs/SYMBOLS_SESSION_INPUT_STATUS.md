# Session room routing, controller snapshots and status sprites

Static File #1 US research, 2026-11-04. [Owned identities and coverage](FUNCTION_INDEX.md). No game launch, attachment, playback, build or runtime measurement. Proposed names describe bounded original instruction behavior, not tested replacement implementations.

The same numeric overlay address can mean different code in a different image; the resident wrappers below are interpreted with the independently reviewed [single-player](SYMBOLS_RESULTS.md) and [network](SYMBOLS_NETWORK_EVENTS.md) callees. Modes2/3 retain their actual fallback rather than an invented online/offline label.
