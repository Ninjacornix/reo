Reliable-type first sequence comes from header8, is passed through1E74E4, then compared unsigned against context5C word0; ordinary sequence compares against context10 and exact equality is admitted. For header0800, traversal starts at payload base and advances by each current header's low10 length. Before copying the next16-byte header it verifies next+16<=packet end. It does not locally require each embedded length>=16, nonzero or <=remaining; the outer limit56 bounds iteration even for zero lengths. The last four trailer bytes are excluded only through the header/length contracts, not a separately computed end here. Earlier [inbound conversion](SYMBOLS_SNAP_PACKET_COPY_AND_HEADER_BYTE_ORDER.md) has distinct validations; whether all entry paths provide them is a caller-admission question.

For each admitted embedded record, allocates from context520 with requested low16 length and direction1/non-strict0, appends the record bytes, sets packet28 to the cached reliable value, and appends to selected queue. Allocation/copy failures are tested with signed<0; queue failure with!=0. Globals1772/1773/1774 identify those paths. There is no local rollback of earlier enqueued original/embedded records or release of an allocated child on later failure.

At ordinary completion, sets original packet payload length to first header low10, then returns original to pool only if first-record admission stayed duplicate. On accepted admission, queue owns original. A rejected original may still have produced accepted embedded records. These separate ownership outcomes must be retained by any native queue replacement; a single accepted/dropped Boolean would lose behavior.
