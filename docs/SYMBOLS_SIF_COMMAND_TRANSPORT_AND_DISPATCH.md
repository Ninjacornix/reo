The initialization poll, outgoing submission, remote destination handshake and interrupt callback are separate stages. Context writes and namespace indices lack local portable synchronization/ownership checks; these guest contracts must be preserved or deliberately replaced in a verified native implementation. No static call count establishes runtime frequency or a bottleneck. See [SIF RPC layer](SYMBOLS_SIF_RPC_CORE.md), [interrupt guards](SYMBOLS_EE_INTERRUPT_GUARDS_AND_HEAP_BREAK.md), [central index](FUNCTION_INDEX.md).
