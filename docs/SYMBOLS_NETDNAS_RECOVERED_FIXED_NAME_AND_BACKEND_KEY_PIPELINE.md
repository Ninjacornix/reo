## Fixed-name operation and limitations

[name formatter](SYMBOLS_NETDNAS_CERTIFICATE_ADAPTERS.md) supply the first two

not rejected before the later comparison path, whose staged metadata is then
unestablished; this review does not invent safe arbitrary-input behavior.
Similarly, the caller accepts any nonzero6FCB40 result, while that adapter copies
metadata out only for result1. The assumed provider boolean/result contract
