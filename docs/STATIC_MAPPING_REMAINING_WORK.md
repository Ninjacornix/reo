## What the remaining work requires

The 81 header partitions are file metadata, including single-byte cuts of MWo3 header fields. Their original image hashes, magic, runtime ID and load base were verified. Naming them as game functions would misstate progress. Their presence in the fixed denominator prevents an honest claim that every catalogue entry is a reconstructed callable function.

[Resident residual admission](STATIC_MAIN_SEMANTIC_RESIDUAL_ADMISSION_INVENTORY.md) separates numeric kernel leaves, optional provider operations, untyped fields and embedded data. A typed consumer, original provider or verified operation contract is needed to improve those roles; an instruction-shaped byte sequence is insufficient.

[Network DNAS boundaries](SYMBOLS_NETDNAS_RESIDUAL_BOUNDARIES.md) and [the independent clear-span audit](STATIC_O4_OUTSIDE_PAYLOAD_RESIDUAL_AUDIT.md) preserve protected entrances, fragments and source-less cuts. [DNAS admission refresh](STATIC_O5_DNAS_RESIDUAL_ADMISSION_REFRESH.md) similarly finds no independent complete clear function among its remaining continuation fragments. Recovering a full protected operation needs additional independently verified body/boundary evidence; clear wrapper analysis alone does not establish it.

[A bounded protected field query](SYMBOLS_NETDNAS_RECOVERED_TWO_BIT_FIELD_QUERY.md) has now been reconstructed as data using its actual entry and restore schedules, independently reviewed, and admitted as one complete operation. This establishes an offline recovery route for further spans; round trips alone do not resolve original function boundaries or justify credit for every fragment.

The [upper-family inventory](STATIC_DNAS_UPPER_RECOVERY_INVENTORY.md) now covers53 reconstructed spans whose connected owners were reviewed. [Primary-family candidates](STATIC_DNAS_PRIMARY_RECOVERY_INVENTORY.md) extend the copied-data method to63 spans, with noncanonical restore paths and inline data requiring individual ownership review. These inventories do not automatically promote internal cuts.

[The o4 owner reconciliation](STATIC_DNAS_O4_OWNER_RECONCILIATION.md) binds all116 protected spans to101 disjoint, hash-verified logical bodies. Its remaining catalogue identities are header partitions or interior cuts, with one verified zero-padding extension. Parent coverage is recorded separately from an independently established function entry.

[The o5 owner reconciliation](STATIC_DNAS_O5_OWNER_RECONCILIATION.md) similarly binds73 protected spans to32 reviewed logical bodies; its remaining9 header partitions and161 interior cuts receive no independent function credit. The resident admission inventory also separates33 embedded-data/byte-boundary identities from executable purpose gaps.

[Exact mechanical leaves](FUNCTION_LEAF_CLASSIFICATIONS.md) have useful instruction-level contracts without invented subsystem names. New purpose annotations require complete owned instructions and supported callers, producers, registrations or provider implementations. The JSON snapshot lists every outstanding identity so new evidence can be reconciled without changing the denominator.

Generated-source gaps need not be permanent unknowns: [five complete raw helpers/callbacks](SYMBOLS_RAW_COMMON_SINE_AND_LOBBY_COMPLETION_CALLBACKS.md) were recovered from owned bytes while retaining their absent generated-source status.
