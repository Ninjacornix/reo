# Resident node palettes, motion binding and whole-tree sampling

Static File #1 US research, 2026-11-04. Source ownership and original instruction
words follow the [central identity/index](FUNCTION_INDEX.md). Read together with
[animation sampling](SYMBOLS_ANIMATION.md), [matrix contracts](SYMBOLS_RENDER_MATH.md)
and [overlay draw/deferred workspace users](SYMBOLS_OVERLAY_MATH.md). No target
execution, build, replay, live attachment or runtime measurement was performed.

The palette builders and gather function prepare matrix data for model parts.
They preserve the original node traversal, signed indices, scratchpad addresses
and matrix multiplication argument order. They do not prove that a palette can
be cached across pose updates, that separate parts can share mutable scratchpad
state, or that host SIMD has equivalent guest floating-point behavior.
