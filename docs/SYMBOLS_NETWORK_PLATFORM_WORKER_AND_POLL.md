Static File #1 US research, 2026-11-04. Original main ELF identity is recorded in the [central index](FUNCTION_INDEX.md). Complete catalogue intervals were read against owned instruction words. No game, connection, build, attachment or benchmark was started. This extends [network state](SYMBOLS_NETWORK_STATE.md), [transport cursors](SYMBOLS_NETWORK_TRANSPORT.md) and [kernel wrappers](SYMBOLS_KERNEL.md).

Addresses and field offsets are hexadecimal. The platform context is a numbered handle, not a raw pointer accepted indiscriminately. Thread scheduling and socket readiness are separate from gameplay updates.

The select-like call uses nfds=context4+10 (decimal), extended to context0+1 when a write descriptor is admitted. The two local sets are each cleared for eight bytes, with fd/64 and fd%64 indexing. The subsequently reviewed [socket layer](SYMBOLS_SNAP_SOCKET_DESCRIPTORS_AND_DATAGRAM_SERVICE.md) allocates logical descriptors0..63 and clamps its scan to64, resolving that range for constructor-admitted descriptors. Arbitrarily mutated context fields are not thereby validated, and these numbers are not arbitrary host fd identities.

The receive request defaults/caps at380 bytes after1E9EE0. The minimum-length test is unsigned: a negative receive result does not take the short-packet rejection by that test alone. The trailer is copied then byte-swapped before its top24 bits are compared; its low byte is not checked there. Error returns, peer admission and child allocator/validator semantics need separate backend contracts before diagnosing a fault.

The readiness result is reset to zero at1DD43C before processing. Branches back to1DD428 test that saved zero, ending this pass rather than draining an unbounded series of datagrams. This literal control flow matters more than assuming a conventional socket-poll loop. No live latency, deadlock, overflow or connection behavior was measured.

Owned-word audit: 13 catalogue rows,780 verified instruction words,89 omitted zero words and no conflicts or omitted nonzero words.
