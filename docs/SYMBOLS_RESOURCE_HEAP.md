# Movable token heap, frame packet allocation and original debug logging

Static File #1 US research, 2026-11-04. Source ownership/instruction evidence
follows the [central index](FUNCTION_INDEX.md). Connected to [render state and
residency](SYMBOLS_RENDER_STATE_CONTROLLER.md) and [frame wait](SYMBOLS.md).
No game, build, replay, runtime measurement, live attachment or file-I/O test.

The movable token heap differs from graphics residency and the fixed two-ended
arena: tokens remain indices while compaction changes payload addresses. Frame
packet allocation can wait for prior-frame completion when its separate active
buffer is exhausted. These are measured static control-flow contracts; neither
one identifies the cause of a captured slowdown without incident evidence.
