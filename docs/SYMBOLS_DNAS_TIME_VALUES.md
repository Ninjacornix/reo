The twelve-word month table at **0x70A488** is `31,28,31,30,31,30,31,31,30,31,30,31`. Leap handling uses **year & 3**, without the Gregorian century exceptions. The structured record uses halfword **year+0, month+2, day+4, hour+6, minute+8, second+A**, word **fraction+C**, and signed halfword **timezone minutes+10**. The parser clears twenty bytes; the final halfword's meaning is not established. Formatting a structured value can modify that value by normalizing its timezone.
