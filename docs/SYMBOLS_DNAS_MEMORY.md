The clear initialization path reserves an inline **0x5E800-byte private arena at 0x711BC0**, initializes **4096-byte page size**, computes shift **12**, sets mask **0xFFF**, and places page metadata at the arena start. Globals at **0x711B00/04/08** are arena start/end/current break; **0x711B0C/10/14** hold page size/shift/mask. Word **0x711B2C** points to page metadata/size-class heads. Free extents use a doubly linked list rooted at **0x711B38**; each descriptor has next/previous +0/+4, extent start/end +8/+C and size +10. Small allocation descriptors include backing page +4, unit size/shift halfwords +8/+A, free/total counts +C/+E and bitmap words from +10. This is private overlay allocation machinery, not proof of the main gameplay heap's behavior.

Protected code must be distinguished from clear prefixes and continuations. The generated source for a protected interval contains original encoded words; its rendered pseudo-instructions do not establish the behavior of the decoded continuation. ## Source-boundary limitations

Catalogue starts **0x6E0920, 0x6E1F5C, 0x6E228C and 0x6E243C** begin in the continuations above. A four-byte `LUI` prefix, a load of a global address or encoded words do not establish four complete standalone function contracts. Their generated files remain present, but this notebook does not invent independent function labels for them. Likewise descriptor words/encoded material may appear as one-byte catalogue rows. This differs from a verified no-op leaf.

Raw words at **0x6E0080** and **0x6E0088** are both `03E00008, 00000000`: return with NOP delay, preserving v0. These helper locations are called by protected diagnostics but have no corresponding function entry in the present o5 catalogue. They are retained as raw context, not added to the mapping count.

The literal one-read spin gates, scans trusting sentinel/bitmap invariants, protected failure paths and recursive release are possible later trace boundaries. Their presence does not show they execute during active-room gameplay, and no runtime timing evidence was gathered here.
