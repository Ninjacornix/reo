# Render-resource packets and compaction relocation

Static File #1 US research, 2026-11-04. [Central identity/index](FUNCTION_INDEX.md),
[token heap](SYMBOLS_RESOURCE_HEAP.md), [frame DMA context](SYMBOLS_IO_DMA.md).
No target execution, build, replay, benchmark or live attachment.

The outer allocator fallback is a complete ordering contract: finish pending
rendering, move heap payloads, then patch references in the tracked render-resource
table. The generic heap compactor does not call relocation hooks by itself.
Existing adapter18DC90 frees a general heap token;18DCA0 resolves its payload.
Neither operation is limited to motion resources or DMA address conversion.
