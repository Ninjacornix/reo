AIFF rate extraction specifically uses the high16 bits of the extended mantissa shifted by the R5900 variable shift count derived from `400E - exponent_low_byte`. Remaining mantissa bytes and a complete IEEE80-bit interpretation are not used. The SSND pointer arithmetic and duplicate recognized-chunk cursor behavior are retained as original contracts; no standards-compliance or malformed-input diagnosis is asserted.

Addresses, offsets, tag values and condition lengths are hexadecimal; spelled counts/4096bytes/bit depths are decimal.
