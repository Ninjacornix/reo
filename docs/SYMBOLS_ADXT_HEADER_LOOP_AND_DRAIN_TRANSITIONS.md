These expressions describe literal signed/modular guest arithmetic; malformed negative metadata is not assumed to be admitted by actual assets. For mode2 memory, padding50 is zero and no file loop callback is installed.

First loop-start callback snapshots predictor state before setting the next sample span. Repeat restores that state after resetting source position/accounting. The end-sample query made by133FE0 before querying start sample has its result discarded. Neither this sequencing nor the loop counters justify assigning an original public enum name beyond the narrow local behavior.

133D10 reserves two spans and searches only once per span, rather than waiting for more input. It does not itself guarantee adequate bytes beyond the parser/scanner child contracts. For first-span success it consumes marker length plus returned magic offset. For second-span success it returns the entire first span free and consumes the found second-span prefix. Restart header failure clears seamless mode; it does not roll back consumed bytes.
