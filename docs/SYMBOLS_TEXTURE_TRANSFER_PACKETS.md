Building these packets is distinct from enqueueing through0x18CFB0, draining frame work through0x18D650/0x18D6C0, and host GPU execution. Packet byte count, payload byte count and mip count have different units. Static analysis does not justify batching/removing packets without preserving register order, DMA end/reference tags, destination strip geometry and referenced-buffer lifetime.
