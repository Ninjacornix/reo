# Overlay o1 title frontend, attraction movies and submenu transitions

Static File #1 US research, 2026-11-04. Same owned o1 identity and full
instruction-byte comparison as [options/movie evidence](SYMBOLS_O1_OPTIONS_MOVIE.md).
No game, build, replay, live attachment, network or real save action ran.

Owned resident pointer table235470 maps menu indices0..5to SINGLE PLAY,
NETWORK PLAY, COLLECTION, CHARALOG, OPTIONS, HDD INSTALL. The table contents
were read from the owned ELF, rather than inferred from translated function names.
The title dispatcher57FC20corroborates these by routing2to collection,3to
character log,4to options and5to installation. Its NETWORK PLAY callback marks
completion immediately; external network startup is a resident transition.

Correction to earlier caller notes:57F580returns to the parent title menu by
resetting state fields. It does not delete or stop a task. The old options and
record notebooks now state that explicitly.
