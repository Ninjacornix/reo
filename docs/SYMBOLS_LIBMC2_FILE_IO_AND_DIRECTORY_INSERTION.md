Path lookup reports existingentry as81010011,missingfinal as81010002 withparententry,missingintermediate as81019FFF. Root andmissingfinalcopy paths do not guardtheentryoutputpointer;existingfoundpathdoes. That distinction is required when replacingtheAPI. [Worker metadata](SYMBOLS_LIBMC2_WORKER_DISPATCH_AND_CONTROL.md) deliberatelymaps81010011to0foropE andcopiesresultmetadataafterlookuperrorsaswell.

Bulk writer186F68 is a write-combining cache,not an immediate400-byte devicewrite. The replacement path retains the priorflush return but still publishes thenewrunandinputpayload,evenwhenoldflushfailed. Same-run admissionrequirescontiguity,maximum8clustersanderasegroup equality;randomwritewithinanexistingrunforcesreplacement. Failedflush behavior is independently documentedin[superblock/device commands](SYMBOLS_LIBMC2_SUPERBLOCK_AND_DEVICE_COMMANDS.md). No measured throughput improvement or actual data-loss case was tested.

Creation and writing decodeclocknibblesasBCD withoutchecking187FF8return; failedclockcanleaveuninitializedtemporarydatebytes. Directoryextension clearsonlythe secondentrymodehalfwordinthenewcluster,notallremainingbytes. Filewrite partial preservation usesbothend-of-chunkandoriginal-file-offsetconditions; it is not an unconditional read-modify-write. Signednegativeoffsets/lengths andintegeroverfloware retained asunadmitted paths,not assertions that ordinary producerspass them.
