Static File #1 US research, 2026-11-04. [Owned identities](FUNCTION_INDEX.md). Continues the [session input staging](SYMBOLS_SESSION_INPUT_STATUS.md) map. No game launch, input injection, attachment, build, benchmark or live-memory read occurred. Original input math and scheduling were not changed.

This layer works on a36-byte polled snapshot at0x2B0A30 and120-byte raw records selected by0x2AFFA8. Those structures are distinct from48-byte normalized port/menu records and actor-bound input. The previously named input status byte0x2AFF18 is populated here as a count of qualifying device headers for the single copied port; callers may sign it separately.
