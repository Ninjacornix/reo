The I/O bridge bodies clear **global36F0DC**, not the caller’s reent errno cell. Their failure copy requires both exact-1 and nonzero global error; successful returns do not clear existing reent errno. This distinction matters for known failure stubs that write error storage through a different helper. No API identity is inferred solely from address adjacency.

The formatted adapters preserve distinct entry ABIs and child calls:10A8C8 constructs a bounded-by-strlen input stream for10EAF0;108E70 passes explicit reent/default stream into10D1E0;10A7A8 builds an effectively unbounded output stream for10D168. Saving floating registers alongside integer slots does not prove the child consumes every saved field. All262 instruction comments match original owned ELF bytes; aligned omissions are zero.
