# Single-player overlay: task steps and interruption masks

Static File #1 US research, 2026-11-04. Catalogue partition **o9**, runtime id **9**, load base **0x810000**, owned MWo3 `single.bin`. This continues [target policies](SYMBOLS_SINGLE_POLICIES.md). Names describe static contracts, not recovered original symbols or replacement code. No game, build, replay, network session, live-memory read, attachment or benchmark occurred.

An important distinction: **0x8217B0 evaluates interruption/completion conditions; it does not dispatch a command from the mask**. It aggregates enabled tests and can decrement a countdown. The adjacent numeric condition table contains stateful task steps that can start actor action 3. These are not all pure predicates. A nonzero task return tells its parent to finish the current policy task; original success/failure/abort vocabulary remains unknown.

Nested state **+FFE** selects a task phase, further state **+FFF** selects an action step, **+103F** selects action-3 behavior, and **+1048 mask 0x4** is completion feedback. Shared step completion usually means +FFF==FF or high-level action +FF8==0, then resets +FFF and returns 1. The 68-byte descriptor bank **0x719A60**, indexed by actor +CA8, supplies flags 0x8/0x10; record and item taxonomy remains unresolved.

Selected interruption-mask contracts are directly recoverable: low mask bit 4 tests actor +BA0 bit 0x200; 0x20 tests +BA0 mask 0x8; 0x40 and 0x10000 test +BA0 mask 0x2; 0x80 tests +C5A==1; 0x2000 compares saved +1051 against 0x8260C0(current +C7C); 0x4000 checks nonzero +C7C with zero signed descriptor/record halfword; 0x8000 checks +1048 mask 0x1 with +C7C==0. Bits 0x100000/0x400000/0x800000 call 0x8139C0 with 1/0x20/0x40. Other bits inspect reference actor state or target-character data at 0x74F295 with 96-byte stride. Those tests establish dependencies, while original gameplay flag names remain unknown.

Timing fields initialized above become interpretable only at their consumers. The +1040 counter is demonstrably decremented per call to 0x8217B0 when its mask enables it; +1042 in F560/F830 is decremented per selected task invocation. Their rates still depend on call frequency, room state and pause/admission gates. None has been measured as wall time or identified as the player's slowdown cause.
