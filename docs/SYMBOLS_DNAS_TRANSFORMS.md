For the arithmetic below, `A=0x09F8ED17`, `B=0xA95128C3`, `L(n)`/`R(n)` mean 32-bit rotate left/right, and `P` permutes input bytes `[b0,b1,b2,b3]` to output bytes `[b1,b3,b0,b2]`, listed from least significant byte. Its inverse `Q` produces `[b2,b0,b3,b1]`. These are executable-range obfuscation primitives; no cryptographic algorithm strength is asserted.

Every primitive walks four-byte words over a signed `start<end` interval and asks 0x6E29B8 whether `(current-address - supplied-base)` is absent from the exception-offset list. Only absent offsets are transformed. All return integer zero. The paired entries below are inverse individual operations; no general pipeline round-trip is asserted without validating selector ordering and descriptors.
