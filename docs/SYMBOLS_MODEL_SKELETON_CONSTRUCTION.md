The independently reviewed callees refine the earlier NBD hypothesis: the optional raw section passed to1CDFE0 constructs a skeleton/node forest or precomputes its static matrices. It is not established as a motion-curve binding operation.1CF560 and the bundle notes now use that corrected role. Material setup, geometry/part construction, skeleton initialization and animation sampling are separate stages.

Retained nodes use an indexed pointer array; several specialized key ranges instead build temporary contiguous400-byte nodes, extract matrix/index caches, release their resource token and invalidate matching caches. Shared temporary bases and fixed arrays mean parallel conversion/caching require ownership and bounds evidence. Static construction work is not proof of per-frame cost or a measured cutscene bottleneck.
