These are resource construction and loading paths, separate from per-update motion evaluation. Raw-block memoization mutates the source bytes and stores narrowed resource tokens; a replacement cache must preserve release/reuse ownership and source lifetime. Static code does not prove repeated loading during a measured hitch.

The original loops use 16-bit entry counters against wider file counts. Bounds, malformed data, divide-by-zero behavior and aliases need explicit parity work before replacement. This notebook records those missing local checks without claiming that the player encountered such inputs.
