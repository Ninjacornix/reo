# Private ordinary-file ADXT game binding

Step 3 remains open. The ordinary source adapter is implemented and selectable
in a coherent private candidate with exact `REO_NATIVE_ADXT=1`, alongside
`REO_NATIVE_AUDIO=1` and the native resource mount. No completed game run has yet
proved this new selection. The player's launcher/build defaults are unchanged.
The native movie logical/physical graph, broader audio consumers and whole-game
transition/error/A-V checks remain required.

## Ownership and boundaries

The installer qualifies the actual pre-run runtime/RAM identity, exact original
registry entries, original code spans and the owned 4,000-byte attenuation table.
It retains the same immutable native resource mount and prepares its canonical
source owner, game-handle map and inert external worker before SDK selection.
Registry wrappers stay inert while the real pre-run lease excludes guest work;
failed preparation restores original entries and joins owned preparations. SDK
success publishes the same aggregate's read-only voice-order capability before
activating the hooks. The installer finishes preparing the binding and changing
registry entries before publication.
A stopped earlier active binding does not authorize another runtime incarnation.

Eighteen entries cover the group service, internal stop, first RNA child
destruction, pause, public ratios/estimated clock/centiseconds/header queries,
before-PCM registration, serviced discard/rebase and unsupported producer boundaries. Original
constructors, AFS/Fname resolution and simple metadata controls remain retained.
The group adopts complete constructor tuples; an incomplete idle constructor may
finish later, while an incomplete active source refuses. Every later access
checks retained child/route identity. Pending C4 file recipes prepare bounded
native views outside source-owner admission, then start through the canonical
facade. Native service replaces the original decoder/RNA group; it does not
start a duplicate original file/PCM producer.

The adapter imports original clock globals without copying native service/reentry
guards. It applies signed attenuation, service divisor, time base, loop and
start-inhibit controls, and mirrors public phase/readiness/request/clock fields.
It preserves the raw loop control on finite headers. Pauses use the qualified
native clock/output control, including the full signed argument. Public clocks
and configured header queries use the actual private source snapshots; original
idle/unconfigured behavior remains retained. Ratio destinations must be bounded,
distinct RAM words outside the fixed audio state pools; aliasing profiles remain
excluded. This is not a bitwise comparison of every caller-saved guest register.

Active native routes must appear in the selected aggregate's actual unsorted
voice order. Only unused idle instances may be appended to make the required
complete permutation. The adapter does not manufacture a playing source order
from C4 slot or raw UID sorting. Old retiring snapshots cannot overwrite the
public state of a new pending source generation.

Internal stop retains the original public callback ordering. The first child
destruction barrier uses the retained native identity even after the original
destructor delay slot cleared C4+C. It waits for actual native source retirement
before delegating child free/reuse. The binding worker itself closes admission
without waiting for guest wrappers, avoiding a cycle with the later source
worker join. Accepted wrappers retain their map/owner; teardown reads no RAM.

## Admitted profile and exclusions

The initial profile admits File1 ordinary mounted file sources with matching
constructor/header channels, positive supported service divisor, default pans,
zero pitch offset, and zero external before-PCM callback. The bounded native
encoded ring is 8 KiB; original captured constructor ring geometry is not
claimed. Native header/window/loop/PCM/clock implementations retain their own
qualified profile limits. Raw original PCM production remains refused by the
selected complete backend.

LSC entry/start, external-SJ start and direct original lower-file start refuse
before original producer effects. Nonzero before-PCM registration, changed child
identity, missing active raw order, unsupported metadata and native source errors
stop the private candidate with a clear boundary diagnostic. They do not fall
back after native selection, invent completion or claim original error recovery.
These exclusions are outstanding integration work, not evidence that the
corresponding consumers are absent from the whole game.

## Verification before the game candidate

Both compilers pass 16 declared-port adapter scenarios. The positive workflow
uses the owned attenuation table and independently inventoried imported mono
and stereo payloads through three real native source workers. It verifies
start gating/readiness/release tick, pause with continued peer consumption,
public clocks and header queries, all finite sample counts/PCM byte digests,
source replacement, child destruction after C4+C clears, and pool reuse with a
new raw route/native generation. Stop/join also succeeds with guest RAM made
inaccessible. Other scenarios cover late/image/entry/mount/worker/registry/factory
refusal and rollback, partial construction, unsupported callback/producer,
changed child identity, missing order, foreign runtime, absent guest depth and
query-state alias refusal. Three deliberately broken adapters are detected:
skipped child retirement, original fallback for an unsupported producer and
ignored child replacement.

These tests execute the actual adapter and native worker/control/data bodies.
Original guest functions, registry/guest ownership, resource acquisition, raw
order and selected factory are explicit declared ports. They do not establish
real runtime admission, original gameplay PCM equality or paced/audio-device
behavior. The separate complete-factory cohort passes 21 scenarios on both
compilers, including exact opt-in routing; its ordinary installer is an explicit
stub in that fixture. Actual SDK130 checks compile the ordinary adapter, handle
router, source preparation and complete factory with both production compilers.

The first factory fixture compile exposed duplicate copied/actual header types.
The ordinary entry header now uses forward declarations, and the fixture's stub
includes its matching private factory declaration. Failed inputs and logs remain
retained. No original/native runtime behavior was inferred from that fixture
compile failure.
