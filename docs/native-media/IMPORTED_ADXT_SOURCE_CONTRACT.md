# Native ADXT sources from verified imported archives

The actual File1 base import retains full NETBIO archive files. Its logical ADX
member sizes therefore do not imply that sector tails are absent. A retained
parent archive can provide the actual rounded source extent without opening an
ISO, inventing zero bytes, widening a standalone logical leaf or changing the
qualified encoded source/decoder. This corrects the earlier blanket PAK-tail
blocker; standalone replacements and other editions remain separate profiles.

The reusable native hierarchy owns one immutable root ByteView and a bounded
cache of parsed AFS indices. It reuses the original-qualified AFS range binder.
Resolution accepts1..8 numeric member indices and returns a retained actual
sector view, logical length and root-relative hop trace. Workers can retain that
view after the tree/mount facade is gone. No mutable source alias or path reopen
escapes. Cache construction allocates metadata before effects; per-archive parse
and returned view allocation remain explicit bounded control operations.

The default cache admits64 archives,65,536 total parsed entries and65,535
members per archive, with constructor hard limits. Accepted immutable ancestors
may remain cached after a deeper failure and stay charged. Invalid members,
unsupported archives, cache/entry limits and source failures return explicit
statuses; no guessed range or synthetic tail substitutes for a refusal. Root
providers must remain externally immutable for the complete view lifetime.

The actual-input fixture uses the unchanged production Windows mount factory,
which hashes every imported file through its retained read handle and validates
the pre-existing File1 manifest. Plain imported archive views are selected by
canonical key, and their actual retained hashes/lengths must equal the pinned
owned-asset inventory. Resolution uses indices only; independently inventoried
root-relative offsets and logical extents are comparison targets, not supplied
read addresses. Facade pseudo-LBAs/read-ahead capacities are never source extents.

One persistent shared output session receives each finite clocked player. Real
native workers read the imported retained views. Copied payload counts/digests
must equal the earlier qualified native decoder; actual per-source joins,
producer retirement, terminal live raw-clock ratios and one final provider join
are checked separately. Device primitives remain modeled. No game, ISO, original
runtime library, RPC/guest publication or experimental path is opened/enabled.

The import manifest's Source field is provenance and is never opened. The
fixture binary has no ISO reader/fallback or ISO-path parameter. Every root's
full hash ties its real padding to the earlier owned inventory; an unsigned
manifest/route hash is not retail-disc attestation or protection against an
already-existing writable mapping. Files/manifest must stay unchanged during
the read-only run. No payload/audio extraction or imported-asset modification
is authorized or required by this fixture.
