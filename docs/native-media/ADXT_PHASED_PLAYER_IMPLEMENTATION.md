# Actual players under native global phases

The finite native player now runs its actual work through the original-qualified
global dispatcher. Both GCC15.2 and bundled LLVM21.1.8 fully replay all **6,706
distinct finite payloads** among **8,910 imported ADX references**, without ISO
reads. Every copied PCM count/digest matches the earlier native decoder baseline.
**Stage3 remains in progress.** No game ran or audio device opened.

The [contract](ADXT_PHASED_PLAYER_CONTRACT.md) separates explicit file-source
polling, decoder visits, one selected playback phase, RNA priming and synchronous
planar output transfer. Ready no longer also executes buffering in its visit;
no player control call hides a source poll, decode or pump. All native players
finish control before transfer. The actual group service word belongs to the
same retained clock context. The original-qualified DTR/DTX envelopes are reused;
an empty native DTX table performs no device-clock advancement.

One atomic mono/stereo copy replaces hardware transport in this admitted native
profile. Actual decoder read credit returns only after the completed output-copy
fence. This is not original per-channel DMA/RPC descriptor parity. Native finite
views/sample limits replace guest file EOF publication; the no-op file-tail
ports do not claim general ADXF/LSC/error continuation. Unsupported loop/header
profiles refuse. Bank/packet and movie ownership remain separate.

Both compilers pass48 finite synthetic cases spanning channel counts, all three
rates, tiny/unaligned totals and multiple encoded windows. Additional actual
worker scenarios check phase boundaries, no hidden source service, independent
slot indices, strong port lifetime, pause/argument2 with two peers, explicit
three-producer mix order, peer progress after a source retires, constructor
rollback, held decoder credit after a real output-counter refusal, and peer
output during a deliberately blocked source join. Assertion counts vary with
worker waiting; scenario coverage defines the qualification. Both parent Release
CTest targets pass; the combined project now registers47 suites.

Three compiling mutations fail the ownership tests under both compilers:
returning decoder credit before output acceptance, omitting RNA priming and
polling a source inside the decoder visit. Fifteen inherited function bodies,
including the atomic pump, observations, pause/estimate/centiseconds and retire
logic, are mechanically identical to the prior qualified clocked player. This
retains that algorithm evidence without claiming a new original full-pipeline
or FPU replay. Only the scheduling composition changed.

The actual imported cohort uses the unchanged Windows retained-handle mount,
real parent archive tails and one persistent output provider. All6,706 files
join their actual source and retire their producer; the provider detaches/stops/
unloads once at the end, with zero occupied producers. Terminal raw-clock ratios
match every file's metadata. Deterministically buffered model consumption has
zero underruns/skips. This is not a real-time, audible-output or stutter test.

All8,910 complete payload result rows match between compilers, including padding.
The native workers needed different numbers of polling/service visits: the runs
record3,836,808 and3,825,088 DTX scans respectively. The comparator preserves this
difference explicitly. These counts are neither audio frames nor game updates,
and do not establish a performance difference.
