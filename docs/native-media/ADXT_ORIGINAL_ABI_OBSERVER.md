# Original ADXT ABI observation before source binding

This opt-in candidate tool records actual original game callers while preserving
their original bodies. It does not activate native source playback. The next
source adapter needs real construction geometry, pending file ranges, callback
registrations, control order and destruction evidence, in addition to the native
handle/controller checks already completed.

`REO_ADXT_OBSERVE_PATH` supplies an absolute path for a new local JSONL file.
The complete audio factory installs the observer only when explicitly requested.
Installation uses the actual pre-run setup lease, RAM identity, exact owned
File #1 code hashes and all 33 original registered entry pointers. Unavailable
observation is a diagnostics error, leaving the original game route operational.
Existing files are never overwritten. No process is attached and no global
input hook, worker thread, game clock change or rendering option is introduced.

Each wrapper delegates the exact original body once, outside every observer
mutex. It preserves guest registers, return values, callbacks and resume PCs.
Original constructor returns determine the resulting handle; destruction has
both before and after observations. Queries count calls without logging every
query. The original service callback records handle state changes and one
periodic sample per 256 calls. It does not itself service or poll any game work.
Snapshots contain value copies of the C4, outer decoder, file descriptor and RNA
records plus a bounded filename, never retained guest memory pointers.

Storage is allocated before guest execution and bounded to 65,536 events.
Overflow drops observations and counts them. Closing capture prevents later
RAM reads, including a wrapper returning from an already accepted original
call. The external worker exports copied values without entering the guest or
waiting for that original call. Export errors are explicit diagnostics failures,
and do not keep runtime teardown retrying forever. The last JSON row records a
completed export; a partial file remains analyzable.

The declared-port cohort compares full RAM and complete context after all 33
delegated calls, checks nested calls and suspended PCs, refuses wrong image/
registration/phase and existing output, exercises overflow, and exports after
making target RAM inaccessible while an original call remains blocked. Both
compilers detect a dropped-original-call fault. Actual SDK130 object checks
compile the observer and its factory independently of that runtime fixture.
These checks do not execute guest constructors or acquire real runtime RAM.

The first object attempt exposed unsupported atomic shared-pointer facilities
in the pinned LLVM standard library and macro argument grouping defects. The
next strict GCC fixture exposed deprecated free atomic shared-pointer functions.
The current publication uses an ordinary short mutex and retained shared pointer.
Historical failed source/receipts remain under `adxt-binding/observer-v1-source`
and `observer-protocol-v1-source`; they are not the qualified current cohort.

`analyze_adxt_observer.py` preserves partial/drop status and evidence line
references. It separates actual ordinary pending-file recipes from LSC entry
calls, whose B4 field can still refer to an earlier source. Metadata observations
do not establish immutable mount admission, native playback equivalence or a
performance root cause. A fresh coherent game build and controlled original
call capture are required next. Step 3 remains open.
