## Results and useful boundaries

- **RTC:** CVX `syRtcGetDate` and Outbreak main `0x1C18E0`/`0x1C1900`, o6 `0x724050`/`0x7240F8` share decimal high/low-nibble interpretation and six clock-byte positions 7/6/5/3/2/1. CVX writes calendar fields/year+2000, zero weekday/moon and returns clock.stat, while ignoring `sceCdReadClock` return. Outbreak o6 rejects read failure/nonzero status then returns epoch-relative seconds. Shared BCD arithmetic does not make the APIs interchangeable.
- **Compiler helpers:** CVX unsigned64-to-single fallback `(u>>1)|(u&1)` followed by conversion/doubling is also visible inside Outbreak `0x11F198`. But that Outbreak owner computes a reciprocal tick rate and calls its own signed64 converter. CVX `__floatdisf`, `__floatdidf` and `dpcmp` bodies are absent from the pinned C/assembly source inventory; six comparison wrappers cannot establish NaN or underlying double-comparison semantics.
- **Heap:** CVX uses static 13,422,592-byte storage, 64-byte HM headers, singly-linked predecessor search and initial tracked free 13,422,528. It ignores `syMallocInit` supplied heap/size. Outbreak `0x1058D8`/`0x106D18` use user-8 boundary tags, bins, neighbor coalescing, requested alignment, locks and optional trimming. No allocator version or heap interoperability was inferred.
- **Controller/vibration:** CVX uses fixed old `scePadRead` byte offsets, port0/slot0 negotiation, static peripheral cache and game repeat/key policy. Outbreak libpad2`0x1804D8`/`0x1807C0` copy variable report payloads and interpret descriptor-selected one/eight-bit fields. CVX vibration owns 20 PAD_ACT records, but the active service visits 19 while all-stop clears 20; this is preserved as local source behaviour, not transplanted into Outbreak.
- **Sound protocol:** CVX Sdr binds services 0/1, with 128 command entries, 512-byte formatter and own status/IOP addresses. Its sound-bank layer adds 20 memoryblock handles, 40 sound slots, forced 10 MIDI slots, checksums, 49152-byte transfer chunks and game port/volume/fade policy. Outbreak CRI PS2RNA/SJRMT service90000200 is a different admitted protocol. Shared SIF/ADXT calls do not equate these backends.
- **Game integrations:** `adxwrap`, `dread`, `pad`, `ps2_event` and `sync` use concrete CVX stream arrays/RDX partition 17, player/weapon model buffers, demo controls, authored stage/room/camera colour tables, task/event flags and vblank/EOR policy. These meaningful game wrappers were explicitly classified rather than treated as generic SDK implementations.
