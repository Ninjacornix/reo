## Findings that change how the references should be used

- **Positive shared GS storage evidence:** every entry of CVX's 32-entry `block_table4`/`block_table8` equals owned Outbreak tables `0x230890`/`0x230910`. CVX's complete inverse 32-bit block-coordinate construction equals owned `0x230790`/`0x230810`. CVX `ClutCopy256` and Outbreak `0x230770` also share the complete 32-entry palette permutation; `ClutCopy` uses only its first 16 selected entries. These are supported storage-format suboperations, not proof of shared model, actor, texture allocator or rendering-engine ABIs.
- **Page-conversion contracts differ:** CVX `Conv4to32`/`Conv8to32` validate power-of-two sizes and copy partial edges into zero-initialized page scratch. Outbreak `0x19E490`/`0x19E7D0` compute rounded page counts and read full 128x128 four-bit or 128x64 eight-bit pages. Its inner block gathers address pitched full pages and pitched output; CVX first gathers contiguous blocks. A caller supplying tightly packed partial pages cannot interchange them without an adapter. Neither path expands palette indices into RGBA colours.
- **More genuine local math matches:** square root (`njSqrt`/main `0x192220`), XYZ length (`njScalor`/`0x191CC0`), dot product (`njInnerProduct`/`0x191DF0`), distance (`njDistanceP2P`/`0x191D10`), 64-byte load-before-store copy (`njCopyMatrix`/`0x191500`), and squared sphere overlap (`njCollisionCheckSS`/o2 `0x61B330`) have supported local roles. Different ABI, EE/VU staging, floating-point path and register/state effects are preserved in the JSON, not hidden behind a transferred original name.
- **Closer normalization lead:** main `0x191D80` is the in-place XYZ VRSQRT form and is closer to `njUnitVector` than the previously compared quadword helper `0x17EC98`. CVX also returns the original length as squared-length times reciprocal length; Outbreak does not implement that same return contract. The existing labels remain correct.
- **Concrete negative examples:** CVX `njFraction` is `n-floorf(n)`, unlike Outbreak `0x192200`/`0x10A2F0`'s signed fractional part (`-1.5` gives `+0.5` versus `-0.5` by their arithmetic). CVX `njTransposeMatrix` stores full scratch quadwords after XYZ-only assignments; Outbreak `0x1911D0` explicitly preserves destination W. CVX `njMultiMatrix`/`njMulMatrixCN` have affine shortcuts and current/register state; main `0x191280` computes the complete four-term XYZW product. CVX `njCalcPoint4` ignores source W for translation and masks XYZ arithmetic, unlike a general 4D transform.
- **Compression is different:** complete CVX `Expand` reads byte controls LSB-first and emits bytes using short/long backreferences. Complete Outbreak `0x1AF5D0` reads MSB-first 16-bit control words and emits halfwords with packed length/distance plus extended zero runs. No decoder identity follows from both being LZ-like.
- **Misleading names are retained as observations:** CVX `njDrawModel` only assigns `vpDummy=model`; `njChangeSystem` only prints. `njCalcTexture` returns literal 1048576. `njWaitVSync` is empty, while actual CVX swap pacing is in `Ps2SwapDBuff`. These definitions are explicitly distinguished from usable draw, mode-change, allocation or pacing implementations.

No demonstrated error requiring a canonical Outbreak math/graphics mapping edit was found. No names or structures were promoted. Existing evidence remains qualified in [ENGINE_SECOND_PASS.md](ENGINE_SECOND_PASS.md), [render math](../SYMBOLS_RENDER_MATH.md), [image loading](../SYMBOLS_TEXTURE_IMAGE_LOADING.md), [texture residency](../SYMBOLS_TEXTURE_RESIDENCY_AND_PACKED_PAGES.md), [Clay conversion](../SYMBOLS_CLAY_RESOURCE_CONVERSION.md) and [animation](../SYMBOLS_ANIMATION.md).
