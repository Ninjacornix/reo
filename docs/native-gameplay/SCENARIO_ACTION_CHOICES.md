# Native scenario action choices and actor conditions

Status, 2026-11-09: interpreter v11 qualifies `135`, `155` and `180` in both ordinary and offline dispatch profiles. They use the canonical native World, primary actor leases and shared Session RNG. No stock script or game caller is installed by this checkpoint. Stage 4 remains incomplete.

`135` first honors the shared linked-list sentinel and the actual `1B0340` actor gate. The gate requires actor category zero; raw mode zero requires actor slot zero, while a nonzero mode requires the slot to equal the canonical selected actor. The selected actor's character byte at original `+B98` is separate from the health class marker at `+B9B`.

The command finds the first type-five node whose common authored ID matches. A used-choice count of eight or more ends the operation. Otherwise it reads **selector 2** from the one canonical Session RNG: this reads the existing observed byte and advances neither seed. Its low two bits select a byte from the owned 16-byte table at `717820`, using the admitted table row 0 through 3. The byte selects one of four authored words. The exact `FFFFFFFF` sentinel, an already used low halfword, or a high halfword other than 8 or the selected actor character ends the operation without selecting a later matching node.

An accepted choice calls the existing complete native type-five reset, enables that node, decrements its common byte counter modulo 256, and stores the selected low halfword OR `4000` in the field reset to `FFFF` by the reset helper. Existing high bits in the selected low halfword remain present. No task, renderer command, notification, new used-ID insertion or RNG advance is invented.

[`ActionChoices`](../../game/native/gameplay_scenario/action_choices.hpp) owns the shared scenario used-ID array, count and table row. Its fixed array contains eight IDs. Counts eight through 255 preserve the original early-return behavior; table rows outside the four observed rows explicitly refuse restoration. The native owner does not infer the meaning of other writers to this shared state. Stock initialization, content registration and those remaining writers remain integration work.

`155` increments the condition ordinal and compares the unsigned authored character byte to the current canonical selected actor. A nonzero selector requires equality; zero requires inequality. `180` increments the ordinal and accepts selector zero when raw mode is zero, or selector one when raw mode is nonzero. Other selectors fail. Both preserve the existing condition-skip algorithm and its flow result.

Programs requiring these dependencies refuse before earlier operations if the World or initial selected actor is absent, the context's actor disagrees with the World, or the choice owner is absent. The offline coordinator borrows the canonical World selected-owner byte and checks every required active actor lease before changing selected context or shared flags. Each command resolves a strong native actor lease; no actor fields or RNG streams are cloned into the VM.

Both compiler cohorts pass 10,167,631 assertions and 11,959 complete original dispatcher invocations, with 5,253 owned instruction comments verified against the owned ELF/overlay. The actual `1B0340`, `1B02D0`, `1B0300` and `1AEC80` bodies execute in the offline oracle. The ordinary dispatcher uses actual raw modes 1 through 3; the offline dispatcher and three-actor wrapper use raw mode zero. Coverage is 313/432 ordinary and 286/432 offline bindings, including original no-op bindings. Fresh earlier linked and saved-control regressions also pass both compilers.

These overlapping counts do not establish complete reachable stock coverage, production admission, runtime caller installation, physical behavior or performance. The oracle's instruction/register/memory scaffolding remains private test code. Native production contains no MIPS execution or guest-memory reads. `131` remains unsupported because it additionally creates a periodic visual-effect task; that task and its actual effect consumer have not been replaced with a placeholder.
