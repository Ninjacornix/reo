# Pose trail admission and ordinary emissions

Qualified 2026-11-12. Stage4 is incomplete. These checks did not launch a game,
open a device, install a candidate or change PC power state.

`PoseTrailAdmission` implements578620's actual type/mode/resource admission.
Mode4 or greater returns before dereferencing actors. Unmapped types and FFFF
resource cells are normal no-effect results. A mapped cell requires its actual
consumer; absence does not become successful telemetry or a placeholder effect.

`MappedPoseTrailEffects` implements the modes0/2/3 constructor and parameter
paths through the canonical168-work/256-piece `PeriodicVisuals`. It uses the
owned708CB0/708CD0/708D40/7123A0 tables, original delay narrowing, actual motion
position or explicit position, and retained native room floors. Mode3 queries
type81 at Y+200, then uses floor height+2.9; a known different surface is a
normal no-effect result. Unknown or retired room generations are unavailable.

The optional `ParticleEdit` capability implements578900 and652F90 on the real
work and its actual children. It preserves the source distinction between
clearing attributes and resetting scale: unit policy scale clears attributes
without overwriting old scale. Zero feedback policy preserves old color,
flags, opacity and scalar. Edits reject retired, recycled, closed or busy
owners. Existing `WorkEdit` vtables and published frame layouts are unchanged.

The five staggered custom5789C0 works of mode1 are still a separate required
consumer. This checkpoint does not claim their movement, impacts or lifetime
are implemented. Explicit-position/nonzero-delay mode1 inputs remain unavailable
through the narrower existing `PoseTrails` interface. An absent consumer is
tested as a failure, including the required initial arc callback.

bytes and executed in comparisons. Owner constructor boundaries use independent
actual native effect owners. Original parameter writes are projected from raw
source output through the independently qualified edit capability; this is
explicitly not an original full update-loop comparison. The trail owner fixture
uses controlled native imported grids. The current CMake contract additionally

separate dependency; full game/frame installation remains an acceptance gate.

qualification rebuilds the live graph and rejects drift. Failed earlier compiler
