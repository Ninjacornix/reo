# Native authored actor request producer and consumers

Status, 2026-11-09: native `100/109` producers and complete `64AE50` consumption are qualified for callback kinds `00`, `05`, `08`, `17` and `28` (hex). These are all kinds observed at the previous conservative owned-prefix frontier. This is an explicit partial callback profile, not proof of every stock path or every byte-valued request kind. No game caller is installed by this checkpoint.

The producers resolve a fresh lease for the canonical selected World actor and write request pending one, low-byte authored kind and a 16-bit parameter (`FFFF` for `100`, authored low half for `109`). Missing canonical actors refuse before earlier Program effects. Programs containing other callback kinds refuse rather than silently queueing unimplemented behavior. Offline category/relation gates match the actual table; no original speed, host time or RNG draw is introduced.

The complete consumer first reads request pending. Zero returns unchanged. A pending request clears its pending byte **before** the actor status-bit `80` rejection; that rejected branch performs no cleanup and needs no kind callback. In the admitted callback profile, `6261D0` clears the canonical session notice byte and status bit `200000`; if the independent actor control-pending byte (`BD0`) is nonzero, it clears that byte, copies held input to history zero, and clears repeat/pressed/released. It preserves later input history, analog state and repeat timer. Consumption then clears status bit `80000` before dispatching the actual callback.

Kind zero repeats cleanup. Kind five sets `BD0` and the session notice byte to one. Kind eight sets action `1/2E/0/0`, invokes the existing qualified canonical action-pose snapshot, then sets subphase two and `BD0` one. Kind `17` sets action `1/D9/0/0` and snapshots. Kind `28` sets status bit `200000` and `BD0` one. These are complete actual callbacks (`6261D0`, `626310`, `6263D0`, `57E840`, `6269B0`) including actual `667370` in the original oracle. Request kind and parameter remain stored after consumption. No successful fake callback or opaque provider is substituted.

An unsupported active kind returns explicit unadmitted status before native effects; the implementation does not pretend to reproduce the original unbounded indirect call. Unsupported kinds on original branches that return before dispatch (pending zero or rejected status) are independently compared. The original physical table extends beyond the previously documented 24-pointer window: the measured kind `28` resolves to `6269B0`; hash-verified pointers through `2A` and the following zero are retained as evidence, not inferred arbitrary-kind bounds.
