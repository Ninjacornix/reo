`ResourceFactory::place` supplies admitted591620 through the canonical native
World, descriptors,64 primary models, shared128 collision records and native
floor Grid. It retires the old primary before allocating its replacement,
publishes the new primary and typed placement state, and preserves owned versus
unowned control flow. This performs real placement, not a successful provider
stub around an isolated matrix function.

Unowned placement uses5B4380's descriptor self-index and real fallback row128;
it does not substitute another content lookup. The bounded profile admits eight
source orientation rows and three angle columns. Nonzero tilt selects the
template distance offset; otherwise the template Y offset is added. Kind0 clears
flag200000 in the descriptor and model. Other kinds preserve that bit. Required
secondary construction uses ResourceCollisions; natural secondary exhaustion
leaves the valid primary present. Canonical RNG initializes pulse timing, and
the actual native Grid floor consumer supplies the draw layer. Its independently
qualified floor policy is an explicitly declared source-oracle seam here.

Floor ownership is retained for one identified room. Binding rejects missing
floors, a different room or a different canonical scene owner; a later room
change refuses unowned placement until rebound. Owned placement follows the
source's early return and does not query floors. Invalid metadata/unknown
capabilities remain unavailable; already measured prefix effects are retained.
The special3200 companion construction remains unavailable upstream, as do the
other five companion contents, delayed work and roots over six parts. SelectorFF
Y-offset aliases outside the admitted129-row table are not guessed into zero.
