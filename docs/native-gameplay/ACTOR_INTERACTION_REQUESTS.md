The request contains kind/parameter, anchorXYZ, a complete orientation word,
travel distance and a logical linked endpoint byte. The source producers at

Their exact instruction slices are audited against the owned overlay; this
message fixture does not execute or migrate those higher bodies. The original

and ABB is the canonical `scene_model` reference. A new request does not create
duplicate pending/model fields. Incoming application sets those same owners,

continues the existing pose/equipment tail. Source action/target consumers reuse

The original sender copies seven words. Three bytes after the endpoint have no
admitted semantic producer/consumer here. Native values omit that padding and
make no legacy wire-compatibility claim. The sender admits supplied requests
with known real model slots0..127. Missing/invalid model capability and authored
NoModel repair remain explicit outgoing refusals. Incoming byte-domain model
values can be stored, but invalid references do not grant later model access.
