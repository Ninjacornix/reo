# Native engine stream channels and script audio

Status, 2026-11-09: the native three-channel engine state, request/stop algorithms, call-based level ramps and actual native-instance adapter are qualified offline. Script `070`/`071` and their identical offline bindings are qualified in interpreter v9. No stock script or game caller is installed by this checkpoint, and Stage 4 remains incomplete.

The [v8 content inventory](SCENARIO_CONTENT_FRONTIERS_V8.md) found `070` as the leading ordinary frontier. Its wrapper calls main `1BA170(0, member, 0)`; `071` calls `1AE190(0)`. These are engine ADX stream controls. They are distinct from synthesized sound-bank requests and from decoded PCM ownership.

## Native ownership and preserved behavior

[`StreamChannels`](../../game/native/gameplay_scenario/stream_channels.hpp) owns three typed channel records and their shared requested-ID cache. A changed ID is cached **before** attempting the start, as in the original. For an unchanged ID, a zero engine pause byte starts directly. A nonzero pause byte queries the decoder phase: phases 0/5 start directly; the other phase values restore the current level, unpause and schedule a target of 127 over 60 engine service calls. The original return value 1 identifies that transition branch; it does not mean playback finished. The script wrapper always returns flow 0.

Start preserves the separate feature gates, negative-archive normalization to archive 0, maximum-level scaling, source start, unpause and final engine-pause clear. Stop clears the engine pause byte and stops the native source without destroying its stable instance. Pause, maximum, current level, ramp step/target and source phase retain their separate meanings. The immutable 128-word engine gain curve at original `234060` has SHA-256 `36fb2dc8488a843da5b2ff8d7538afee1af1edbdb005746582e79cdd80032387`.

The level calculation preserves division by 127, multiplication by the current maximum, the checked conversion policy, low-seven-bit selection and signed gain-table division by 10. Restoring a current or maximum value through this setter scales it again; it is not replaced by direct assignment. The maximum setter preserves an existing float at or below the new maximum, including negative zero at maximum 0. A zero-duration ramp records signed maximum finite, matching the owned division at `1AE458`; the production owner stores no CPU exception flags or register state.

Only an explicit `StreamChannels::service` advances engine ramps. The original service ends with `12BEF8 → 142008 → 141E20(5)`, which invokes registered group-5 callbacks. This is not treated as an IOP/RPC no-op. The native backend services the actual existing `adxt_instances::Instances` at the supplied audio/SDK tick. Independent source pumps may service that same native owner repeatedly; they do not call the engine ramp service or invent another game tick.

[`StreamInstances`](../../game/native/gameplay_scenario/stream_instances.hpp) creates three native instances under a fresh, empty canonical control owner. The caller supplies an explicit permutation for mixer summation; the adapter does not infer production order from channel numbers. It uses existing native start, stop, pause, attenuation, observation, source retirement and service implementations. There are no guest handles, RAM reads, MIPS calls, UI dependencies or physical audio-device calls in this adapter.

A sealed `StreamAssetCatalog` retains native, bounded AFS indexes. Member resolution and resident-view preparation occur outside canonical instance admission and do not read the member body. Existing source workers load the retained immutable member before decoder readiness. Catalog domain and archive identity prevent equal caller labels from aliasing different catalog owners. Existing resident-view limits and memory accounting still apply, with explicit refusal rather than a hidden source fallback. Actual archive registration from the admitted resource mount remains a game-caller gate.

SDK phase 0 after stop is logical control state, not proof that a child worker has joined. Actual final decoder snapshots remain available through the native instance evidence. Tests wait for idle instance state, completed stop count and the retained snapshot's real `retired` proof; they do not incorrectly require that evidence to disappear.

## Qualification

The engine-state cohorts `gameplay-stream-channels-llvm-v7` and `gameplay-stream-channels-gcc-v6` each pass **680,532 assertions and 18,432 original entry calls**, with **702 owned instruction comments** checked. Complete original request/start/stop/pause/resume/level/maximum/ramp/service bodies are compared through declared primitive SDK test ports. Tests preserve callback ordering and the engine state visible at each callback. The fixed curve is checked against the owned File1 ELF, SHA-256 `06bd5fd7243144cd30cdd0c0023763a369738cb91b177b35e85f6a4782b4ca46`.

The numeric admission profile permits nonnegative maxima/current levels up to 323, covering the original byte-percentage initializer's range, with finite canonical level/step state. Invalid restoration and nonfinite service quantization refuse explicitly before publication. Earlier synthetic negative/outlier experiments exposed a checked-runtime `MFC1` zero-extension question at `1AE5C0`/`1AE5C8`; that behavior was removed from the production policy. It is an independent compiler/ISA audit, not a claim about physical PS2 behavior. Failed and exploratory cohorts remain retained; the final qualification cites the admitted-profile cohorts above.

The real native-instance cohorts use the owned BGM member `NETBIO01.DAT/1/69`, 3,637,248 bytes, SHA-256 `f6fc3d252472720860b71ebfa8c63536de2ff73726ab0b63fb4bd607a9d62231`. Its bytes are placed in a declared synthetic bounded AFS fixture for these API tests. This proves decoder/instance integration with that owned payload, not stock archive-route admission. The separate 1,000-word native SDK attenuation table is checked at `220498`, SHA-256 `ba7a4e40b40741d52daddb3e80bf6c55d0ddcf93df46580ba6de9ad8c5e9c138`.

Those tests cover asynchronous full-body materialization, a bounded stop request while the body provider is gated, actual canceled-source retirement, two stereo sources and a mono peer, pause/resume without replacement, invalid-source refusal preserving the active source and final joined teardown. During a two-second wall-clock interval, only the owned BGM channel renders while a separate source pump repeatedly services the real native owner at tick 1000. Native output has zero measured underrun frames. A prepared **nonzero** engine ramp and canonical level remain unchanged during that interval; one subsequent explicit engine service advances them. Software render-call cadence is test input, not proof of real-time hardware output, physical audibility or game speed.

The combined interpreter cohorts `gameplay-scenario-llvm-v17` and `gameplay-scenario-gcc-v14` each pass **3,007,264 assertions and 3,187 original dispatcher calls**, retaining the earlier 65,536 numeric opcode-16 comparisons. They check **4,334 owned instruction comments** across overlay and main sources. New ordinary/offline cases exercise actual main request/stop bodies through primitive SDK ports, every offline category/relation gate, explicit audio ticks 0/1234 and both coordinator routes, including three active actors sharing a saved script record.

`TickContext.stream_tick` is optional and defaults to unavailable. Programs requiring stream controls refuse a missing tick, owner or backend before script effects. Explicit tick 0 is valid. The offline wrapper preflights every active admitted channel before changing selected actor or shared flag state, then forwards the same supplied tick through both routes. This tick must come from the actual SDK/audio clock owner; it must not be synthesized from host time or substituted with the task/simulation clock.

Current masks are **308/432 ordinary** and **281/432 offline actor**, including original no-op bindings. Exact source, compiler, input and receipt hashes are recorded in [v9 qualification](../../tools/native_reconstruction/gameplay_scenario_qualification_v9.json).
