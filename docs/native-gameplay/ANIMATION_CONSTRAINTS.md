# Native model constraints and ground targets

2026-11-09: `animation::Constraints` owns the seven typed contexts and per-node callback bindings used by original `5D5FA0`, `5D6850`, `5D59A0`, `5D5BE0`, `5D5AB0/5D5AD0` and `5D6400`. It retains the exact native `Instance`; `Actor.constraints` is the canonical owner. Native production stores matrices, vectors, node ordinals and typed callback kinds. It has no original RAM, CPU registers, resource handles, instruction executor or generated-function calls. This component completes the previously open primary ground/constraint path under the profiles below. It does not install the native World in the running game or complete Stage4.

The constructor uses the actual owned skeleton baseline translations to form three scaled frames, measures both segment lengths, and computes relative output frames. Mode1 transforms its auxiliary direction by the parent; mode2 forms the auxiliary from the separate reference point. Original output pointers are the first and middle nodes, not the middle and endpoint. The three callbacks are first-node two-link solving, the actual empty middle-node callback, and endpoint standard publication. The source leaves targetAC untouched during construction; native reinitialization preserves it. ReferenceA0, targetAC, twist84 and bendBC remain distinct fields.

`constraint_math` implements the exact XY/XZ basis, scaled inverse and direct-X rotation bodies. The inverse follows both ordered reciprocal-square-root passes rather than substituting a single division by squared length. The solver uses the original squared-distance expression for the cosine laws and its full-extension branch. It does not invent cosine clamping. The qualified SDK VSQRT path clamps a negative radicand to zero. Zero/parallel-vector normalization uses that SDK's finite reciprocal-square-root fallback. Physical PS2 exceptional flags and arbitrary nonfinite/overflow behavior are not claimed; consumed finite values, strict round-to-nearest FP32, gradual underflow and no contraction are required.

Constraint traversal preserves `5D5AD0` ordering. Standard callbacks update the child scale; the solver and empty callback leave the incoming staged child scale unchanged. Missing or disabled node callbacks preserve the already computed standard world matrix. The preliminary solver publication reads the authored parent's sampled scale. A complete pass publishes an immutable joint snapshot only after all callbacks finish; failures invalidate the current ready snapshot while retained older snapshots remain immutable. Mutable models/contexts belong to the serialized simulation owner.

`initialize_model_constraints` implements the actual signed-pause creation contract: nonzero `World.paused` leaves the component untouched; otherwise the two mirrored mode2 chains are nodes7/8/9 and4/5/6 with the owned twist constants and auxiliary vectors. The direct original calls are in actor construction `66A750` at66AB78/66AB9C, cutscene commands `5EEC50` at5EEEE4/5EEFA4, and restore `5F0610` at5F0708/5F07F8/5F09D8. These are actual behavior-owned creation paths, rather than a renderer inventing valid contexts. A bounded scan of File1 main/o2 source finds only constructor5D5FA0 directly storing a halfword at context offset82, writing1. This is not proof about every possible aliased block/word write. No guessed disable API or additional stock creator is claimed.

Explicit model recreation creates a new constraint owner and reinitializes its first two chains. Source constructor-untouched targets and floor caches survive; an externally retained old owner continues retaining its original model. The active consumer refuses a missing owner or one whose `model()` differs from current `Actor.model`. Recreating additional enabled slots2..6 is refused until their behavior-owned creator is identified. The generic typed constructor and literal seven-slot enabled count are implemented; this does not imply that stock callers create all seven slots.

`rebuild_model_constraints` owns the common frameModel position/root-scale/height-correction prelude and complete `5D6400` ground policy. Linked actors, mask0x12 and every nonzero signed pause value use standard publication without consulting constraints or floor data. A present, known-zero component also admits standard publication; an absent component never becomes presumed all-disabled success. If only slots2..6 are enabled, base-height metadata and standard joints are computed, but the original first-two-slot check performs no floor query.

When either first context is enabled, both targets and reference points are prepared from real world nodes9/7 and6/4; both floor queries use endpointXZ with canonical ActorY. Both queries complete before either targetY clamp. Each height uses the original surface-kind-dependent addition order; only upward adjustment occurs. Any raised endpoint causes the full callback traversal. Actor position is unchanged. Category>2 combined with surface_kind1 is explicitly unsupported because the original floor-mask register is unassigned on that path; it is not assigned a convenient value by native code.
