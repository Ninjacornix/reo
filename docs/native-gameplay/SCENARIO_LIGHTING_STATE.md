The native importer follows the actual loader's truncation and reset behavior: source bank kind/count words narrow to halfwords; positive top-level count controls iteration; zero/negative top-level count still resets work. Unsupported version clears imported banks while retaining existing work, as the original early branch does. Valid version resets the work after copying the banks. Malformed extents, more than four banks or more than32 entries refuse before changing the native owner; original out-of-owner unchecked accesses are not supported. All166 owned RDT sectionB payloads are hash-verified and fit this profile. This is not proof for unlocated or other-version content.

The primary pool preserves first-free allocation, byte tags/modes, retained payload on null-source allocation and clearing on accepted release. Create rejects attenuation when `<=0`; NaN therefore passes, matching6B20A0's ordered comparison. It clears the old bank binding's active slot first, then allocates and sets the bank's enabled bit even when the pool is full. Removal clears the mask but deliberately leaves the binding itself. Internal bindings name fixed native pool slots, so a later reused slot is affected by that retained binding just as in the original; no generation filter silently changes this behavior. Reset clears bindings, pools and selection, while existing bank masks are left intact. Public snapshots avoid exposing guest pointer identities.
