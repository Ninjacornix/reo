# Placed-resource collision construction

`ResourceCollisions` supplies complete591860/5C62F0 construction and replacement
through canonical SceneResources and the existing shared128 scene records.
Typed descriptor position, angles and shape/placement selectors replace the
original descriptor and stack addresses. Generation-checked secondary
attachments retain the actual scene record used by collision views. No new
collision-only pool or mutable shadow is introduced.

The admitted File1 profile contains20 source-identified40-byte shape rows from
723340..723660. This is a bounded admission, not a newly proven authored table
count.5927F0 rotates the four integer X/Z vertices using the complete370320
angle policy, adds descriptor position and truncates to signed integer points.
591860 truncates Y before adding the two signed height offsets with modulo32
addition. Conversion comparisons use finite, representable int32 inputs;
exceptional/out-of-range physical PS2 arithmetic is not claimed.

The constructor retires an existing valid secondary before allocating its
replacement. Natural shared-pool exhaustion clears the secondary and reports
full. Unknown, foreign or retired secondary capabilities and unavailable shape
profiles refuse before retiring valid native state. These are explicit native
admission limits, not guessed source-pointer recovery behavior. Resource/control
identities and collision fields occupy the same canonical record.

Both compilers pass2,625,426 assertions, including every65,536 yaw value for all20
rows (1,310,720 footprints),128 full constructions and128 replacements. They
execute53,751,726 original calls. The complete original placement, pool and math
bodies execute; only bounded byte copy/zeroing are declared private oracle
ports. Tests also compare list order, all record fields consumed by collision,
full-pool replacement, exhaustion, retained retirement, foreign/stale identities,
missing owners and invalid geometry. Parent libraries build and all four World/
body/collision-phase/contact tests pass for both compilers. Evidence is sealed
in `native_resource_collisions_qualification_v1.json`.
