# Scenario flag predicates: interpreter v3

Status, 2026-11-09: additional native flag algorithms qualified against the original dispatcher. The interpreter remains partially supported and uninstalled in the game. This extends the frozen [resource lifecycle v2](SCENARIO_RESOURCE_LIFECYCLE.md) boundary without changing its native resource helper implementation.

This version implements ordinary E3/E6/EC/ED/EF, strided conditions B7/B8 and strided writes F4/F5. E3 reads the local primary bank; E6 reads shared secondary; EC tests shared scenario set and secondary clear; ED applies the same expression to local primary/auxiliary. These pair predicates preserve short-circuit reads and compare the expression to payload word+4 being nonzero. Ordinary EF takes both its ID and desired value from **unsigned bytes**, while its offline counterpart takes **whole words**. Treating those as identical would misread authored commands.

The separate offline E3/ED/EF bodies are implemented through canonical native `FlagState`. Category zero reads the first local bank, unlike a category-zero write, which broadcasts to all three. Categories1..3 select their corresponding local bank; category4 preserves the primary→auxiliary0 and auxiliary→scenario aliases. The source table's three independent dispatch gates remain in force. The native code neither copies the ordinary table's coverage over the offline table nor evaluates a provider by converting an original address.

B7/B8 test strided halfword slots2/0 respectively. F4/F5 set/clear slot5 without notification. The mask is a 32-bit variable shift followed by a halfword truncation. Bit indices16..31 therefore produce a zero halfword mask, while32 wraps to bit0. The typed `Flags::test_strided` capability defaults to unavailable; the canonical owner implements it with bounded native storage. A third-party provider must supply that capability explicitly.

Both focused compiler cohorts pass **92,149 assertions,825 original dispatcher invocations and2,552 checked owned instruction comments each**. Private outputs are `build-native-sjuni/gameplay-scenario-llvm-v8` and `build-native-sjuni/gameplay-scenario-gcc-v6`. All earlier ordinary/resource tests remain included. New ordinary cases test all four primary/auxiliary bit combinations, desired values0/1/100hex, high-byte truncation for EF and six strided shift boundaries. Existing complete offline dispatcher/wrapper transcripts now also contain these predicates, including offline EF ID257 and a nonzero desired word whose low byte is zero. Current positions, condition ordinals, all flag banks, counters and strided state match the original bodies.
