[scene_resources.hpp](../../game/native/gameplay_scenario/scene_resources.hpp) owns256 typed descriptors with domain/generation identities. A retired or reused slot, a different world and a default identity cannot alias a current descriptor. Resource identities are distinct from immutable resource-file handles and from native actor `EntityId`. A descriptor contains only native values and shared native attachment capabilities; it contains no guest address or copied runtime record layout. `SceneAttachment` exposes the one observed mirrored flag operation. Its implementation belongs to the actual native scene-object owner.

Two original searches must remain distinct. Helper592900 first rejects a nonpositive signed16 authored ID, then returns the first of256 descriptors whose unsigned authored ID matches, without an active filter. Helper5B4A50 searches the separate attachment ID, requiring active nonzero, flags bit1, and a positive unsigned ownership tag; it returns the captured owner tag minus one. Native `lookup` and `lookup_attached` preserve these mechanics, including first-match order and inactive plain-ID matches. Negative attachment IDs cannot equal an unsigned descriptor ID. The owner is resolved through a typed provider into a real native actor identity, with primary references0..3 and the separate extended reference family preserved. No original pointer is converted into an `EntityId`.
