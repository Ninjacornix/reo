# Native owned skeletons, joint poses and root translation

2026-11-09: native `animation::Skeleton` and `animation::Instance` now import real model forests, own sampled node state, bind real [motion clips](ANIMATION_CURVES.md) by track group, publish recursive joint matrices and extract root translation. The canonical World Actor owns its mutable model instance through `Actor.model`; immutable Skeleton/Clip definitions can be shared. Position, actor basis and output root-motion delta remain canonical Actor fields. Production code has no original RAM/register state, resource handles, instruction interpreter or generated-function calls. No native World installation, game launch or whole Stage4 completion is claimed.

The raw forest importer follows `1A2E00` packing: type0 supplies root indices, nonzero records supply nodes, selected root/child/sibling traversal determines the forest count, and the contiguous source interval determines native joint ordinals. Child/sibling indices are rebased to that interval. Palette ID, track ID and signed static index remain distinct, as do baseline parameters, sampled parameters, local matrices and world matrices. Cyclic/shared/out-of-range links, noncontiguous packing profiles, invalid extents and nonfinite consumed defaults are refused. Admission is bounded to1152 nodes, matching the original model-node pool capacity. No unrelated mesh/material section is treated as a skeleton.

The actual `P00_00.nbd` forest has36 nodes grouped by track IDs0/1/2/3/4 with counts10/12/6/4/4. These counts explain the real motion-clip cardinalities; they are not guessed from a synthetic hierarchy. Binding retains a native immutable Clip and assigns its tracks to matching nodes in original depth-first order. Missing or incompatible groups fail explicitly. Binding/clearing preserves per-channel caches, and sampling resets matching nodes from their authored defaults before decoding curves in source order. Clearing a binding leaves the current sampled pose until the next sample, matching the original separation of operations.

Local pose construction follows `1939A0` and the original direct-radian Euler chain. It does not explicitly apply scale parameters; recursive `193240/193260` publication supplies scale separately. Publication composes only three ordered XYZ terms for `1913E0`, applies the source reciprocal-parent-scale/translation compensation, then the parent matrix. Children inherit their current parent's sampled scale, while siblings retain the original incoming parent/scale. Actor model scale overwrites root local matrix40 through the actual `18FE60` policy. The external actor/object basis is an input to publication and is not stored as a second canonical actor basis.

`consume_root_translation` implements the actual `58C6A0` read/subtract/save/clear contract: second node local translation minus the model owner's previous root reference becomes the returned delta, the reference is updated, then only the second node matrix translation is cleared. Sampled translation parameters remain distinct. `translation_difference` follows `1925C0`: two complete scaled matrix evaluations update the same per-node caches in source order, then end translation minus start translation is returned. These operations are separate from applying the delta to Actor position. The complete `58BF50` `FrameRecord` advancement policy is native, including transient flag clearing, the hold bit, zero-duration result3, one-wrap/clamp behavior, positive look-ahead and negative-step quirks. Callers supply the original game step; no host-time or speed change is introduced.

Joint publication creates an immutable `JointSnapshot` only after a complete successful rebuild. Binding, sampling, root-scale or local/root translation changes invalidate the current snapshot. Older retained snapshots survive later mutation and native Actor/model retirement. Mutable Instance calls belong to the serialized simulation owner; each Actor must have its own mutable Instance, while immutable definitions and snapshot leases can be shared. Bind-inverse/render palettes are **not** implemented by this component: the fixture executes the full original constructor including that computation, but native parity here concerns baseline/current/local/topology and gameplay world-joint outputs, not the unused render-palette product.

The new World consumer `correct_model_height` implements the complete `5D6FC0` policy. It honors the canonical **signed `World.paused` (original4BADF8)** and only skips B40 when paused is nonzero and B40 equals1. It reads the previous world height of joint21, computes `(jointY-actorY)-47.04999923706055`, and returns when that excess is nonpositive. Categories0/1 use `AA8 * (modelScaleY/referenceScale)`; category2 uses AA8; others use zero. The original `(excess*gain)/67.69000244140625` value is clamped **up to** gain by the ordered comparison, then only local root node1 Y is written. This does not move Actor position.

`File1ModelCorrectionScales` is a concrete owned native metadata provider, not a successful-default stub. It contains eight player scales and125 NPC variants. The identity-checked `1AA740` loader derives an NPC filename index as `BB4-1`; the125 original named `N*.NBD` entries therefore define admitted variant IDs. Every scale bit is bound to the corresponding owned o2 table location. The offline profile receipt seals the complete archive name table and original loader instruction proof. Unsupported player/variant IDs throw; missing metadata is never replaced with unit scale. This metadata coverage does not claim that125 NPC skeleton or behavior paths have been ported.

`rebuild_standard_model` performs the real frameModel position/root-scale/correction prelude and the standard `376D50` publication. Both standard primary and linked-actor routes are compared with complete original `3769F0/376AE0` execution under the explicit attachment-free profile. The primary `5D6400` **paused fast-path** is also admitted and executed in the original comparison. An unpaused primary request without mask0x12 still requires typed constraint ownership and fails visibly after the original common prelude. Missing context data is not interpreted as seven disabled contexts. That owner is the next component. Nonzero attachment `662DB0`, linked-object `376B80/58F7A0` setup and callback-driven constraint reconstruction remain explicit separate paths; this helper does not claim to replace those complete traversals.

`WorldModelPoses` supplies real immutable joints to `WorldBodies`, validates current World/entity identity and refuses unpublished, retired or foreign generations. Publication also supplies `Actor.collision.joint_two_position` from actual world joint2 when present; it does not invent a joint for short models. A real WorldBodies integration case uses two separately owned native model instances and joint-relative body spheres, receives contacts and resolves them. Actor/model retirement leaves an already retained immutable joint lease valid. The coordinator must schedule publication, body consumers and later pose mutation in the actual original frame order; the adapter does not lazily rebuild a model during a body query.
