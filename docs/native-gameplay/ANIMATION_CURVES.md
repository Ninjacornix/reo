# Native owned motion clips and six curve formats

2026-11-09: `animation::Clip` now imports original raw curve-set bytes into owned immutable native tracks/keys. `Curve::sample` implements float and signed16 linear, cubic and mixed formats (`21/22/23/11/12/13`). Playback requires no original resource handles, global packing arena, RAM pointers, instruction execution or generated functions. This is the curve/data layer; skeleton ownership, animation banks/descriptor selection, recursive joint pose, actor root extraction, installation and game retest remain separate work.

The offline corpus is taken from the player's identity-checked File1 import. It retains two original player NBD assets (`P00_00.nbd`, `HP00.nbd`) and two original motion banks (`pc_000.bin`, `pc_001.bin`). Four evenly distributed live entries per group in both adjacent20-descriptor bank tables yield59 distinct real clips. The private corpus receipt records archive member offsets, original member hashes, selected logical bank/group/entry, clip offsets/hashes and extracted skeleton-section identities. Files stay in `build-native-sjuni/animation-owned-corpus-v2`; original assets are untouched and no game runs.

The native importer follows the real raw channel layouts and one-hot channel selectors, retaining source track/channel order and native per-channel signed16 cache indices. Sampling clamps endpoints, honors an exact cached key, walks backward/forward from that cache and selects a strict bracketing interval. One stock selected clip contains **duplicate key times**. The original finder handles nondecreasing time sequences without choosing a zero-length interpolation interval; demanding strictly increasing times would reject valid stock content. Native sampling therefore admits duplicates and preserves the cache-selected exact-key behavior. It refuses descending/nonfinite keys, empty key payloads, counts beyond the admitted signed cache range and malformed extents.

Linear evaluation retains the original reciprocal/slope/intercept operation order. Cubic evaluation follows the full `18F260` polynomial in separately rounded FP32 operations, including its tangent terms. Mixed records choose linear/cubic by the leading segment word; the original defined zero result for other segment words is retained. Quantized mode2 multiplies rotation channels3/4/5 by the owned `241C98` turn scale (`0x39C90FDB`) and divides other channels by16, in source channel order. Native output and caches remain mutable instance state; Clip/Curve definitions are immutable after import.

Inactive raw channel descriptors are deliberately unsupported: their original packed type20 has no defined sampler return and can inherit an earlier FPU value. The importer refuses those clips rather than inventing zero/default output. The current profile also requires a one-hot selector, known raw modes1/2, bounded nonempty channels and finite data. Unsupported assets fail explicitly; none of the59 admitted real clips needed a synthetic replacement. No host wall-time scaling or original game speed change is introduced.

Each compiler passes **274,204 checks**:65 clips (59 owned +6 format fixtures),1,465 curves,67,854 forward/backward samples,33,827 complete channel/quantization/cache cases and five explicit malformed/undefined admission refusals. The fixtures execute the **actual complete original raw conversion/packing chain**, then actual original samplers and `193C80` channel decoder. Native imported track/channel counts, modes, durations, loop metadata, exact FP32 values and cache effects are compared. There are641,283 original helper invocations per compiler. Original-body SIMD/register surroundings are test-only; production uses ordinary C++ native values.

LLVM: `build-native-sjuni/animation-curves-llvm-v4/receipt.json`; GCC: `build-native-sjuni/animation-curves-gcc-v2/receipt.json`. Their source sets/results are identical and source/output copies are sealed. Earlier failed/passing checkpoints remain preserved: LLVM v1 needed test-only VU status/sqrt surroundings; LLVM v2 exposed the real duplicate-time admission issue; GCC v1 required formatting fixes under strict warnings. These are isolated source/content comparisons, not game failures or a demonstrated slowdown fix.

Reproduce corpus collection with `tools/native_reconstruction/animation/import_owned_assets.py --data ORIGINAL_IMPORT_DATA --output NEW_CORPUS_DIRECTORY`, then `animation/verify_curves.py --compiler ... --corpus CORPUS --output NEW_DIRECTORY`. The qualification JSON binds exact source, ELF word proofs, compilers, corpus and both results. The required profile is finite FP32, round-to-nearest, gradual underflow, no fast math or contraction. Physical PS2 exceptional behavior/flags and arbitrary malformed original-memory behavior are not claimed. This component does not complete native animation/model ownership or Stage4.
