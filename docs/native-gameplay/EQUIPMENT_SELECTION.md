# Native primary equipment selection

Status: admitted primary selection qualified on LLVM and GCC. Not installed in
the game; Stage4 is incomplete. No game, game window or audio device was used.

`Equipment::select` supplies complete admitted666DE0 behavior through the actual
canonical World, descriptor/template owners, model construction, shared secondary
release and weapon/audio resource owner. Input0 is a no-op. Other inputs inspect
eligibility through the requested descriptor's authored self-index. A metadata
descriptor that is inactive, template255 or lacks flag1 leaves selection and
action state unchanged. This is distinct from the requested descriptor's own
activity/template state, which later construction/action helpers inspect.

For an admitted canonical primary actor, selection writes its resource handle,
sets the descriptor's owner to slot+1, performs actual attachment construction,
then computes the action through5F1F70/5B4D50. The action is signed template
byte15, published as its16-bit representation. Inactive or template255 selected
resources produce action0. Actor activity is not an invented selection gate.
Full model pools and full sound queues preserve the later action update.

Unavailable reached owners stop before action publication and retain the actual
selection/model prefix. Foreign/stale identities, linked actors, unknown primary
population and closed Worlds are explicit boundaries. Extended-family
model_variant+5 ownership remains unimplemented. Input handles are typed bytes;
the comparison does not claim arbitrary high-bit alias behavior for invalid
callers.

Both compilers pass18,379,335 combined assertions. The selection part covers:

- 1,288 selections: all256 action-byte patterns on all four canonical actors,
  descriptor/self-index activity, missing templates, high flag bits, and input0.
- Eight full-capacity cases: a full named-bank queue and a full primary model
  pool for each canonical actor, including later CA8 publication.
- Sixteen reached-prefix/lifetime refusals, including preservation of the prior
  action value after unknown population, invalid identities, linked actors and
  closed World behavior.

Actual model identities/list links, secondary lifetimes, ownership fields,
animation banks, bounded sound enqueue and action values are compared with the
complete owned source bodies. The combined run retains the actual ROM/SND/PCM
and preceding attachment/resource/inventory checks. Parent builds and all four
World/collision regressions pass with both compilers. Exact source hashes,
instruction-audit summaries and retained complete receipts are sealed in
`native_equipment_selection_qualification_v1.json`.

The first test cohort attempted an absent reset convenience API. The corrected
test retires each real source/native model through its actual lifecycle; its
failed compile receipt is retained. Production code needed no reset substitute.

Equipment use, recipes, transfer, extended actors, six special companion visual
families, native room installation and game acceptance remain open.
