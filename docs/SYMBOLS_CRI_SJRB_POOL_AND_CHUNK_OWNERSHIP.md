`13F8A8` creates an SJRB object in a fixed pool of256 records, each **64 bytes (0x40)**. Its data storage belongs to the caller. The object tracks two pools: selector0 is free/write capacity; selector1 is published/readable data. GetChunk reserves from a pool, PutChunk returns a span to the selected pool, and UngetChunk reverses the most recent position when the supplied span matches. These are original CRI tagged critical-section operations, not a verified portable acquire/release SPSC protocol.
