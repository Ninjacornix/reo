## Source of names and evidence

[annotations.json](../tools/function_index/annotations.json) stores image/address,
proposed name, confidence, full confidence qualifiers, rationale and notebook
path/line evidence for each reviewed entry. The notes remain readable context.
After editing notebook tables, re-import annotations and review that JSON diff.

The extractor never guesses a semantic name from a call relationship or upgrades
an annotation's confidence. It preserves original catalogue symbols and marks
unannotated entries `unknown`. Overlay labels identify map/source partitions and
must not be treated as runtime overlay IDs without checking image identity.

## Useful commands

Run from the checkout root:

```powershell
python tools/function_index/index.py search animation
python tools/function_index/index.py search "ST_HIT"
python tools/function_index/index.py show main:0x00141E20
python tools/function_index/index.py show 0x193178
python tools/function_index/index.py refs 0x264820
python tools/function_index/index.py suggest --limit 20
```

`show` provides callers, callees, instruction sites, source locations, referenced
addresses/strings, and reviewed notebook evidence. Indirect calls and switch
