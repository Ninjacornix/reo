Class sizes EC/22C/3AC are decimal236/556/940 bytes, giving admitted payload capacities192/512/896 after44-byte metadata. Context construction requests class counts110/15/10 decimal. These capacities describe guest pool storage; there is no host allocation or observed telemetry in this notebook.

Allocation rejection statistics distinguish forward-direction58 from reverse-direction54 for low-water/empty classes. Final status can remain-1F3C when no class fits; an attempted empty pop can leave-1B56. A free count equal to its threshold neither sets a previously clear low-water flag on allocation nor clears a previously set one on release. This hysteresis and the strict caller option are retained literally.

The optional hook dispatcher always passes selector1, although callers request1/2/3. It would be premature to rename these hooks mutex lock/unlock/destruction. Early returns after a visitor or post-mutation hook error preserve the exact partial effects. No concurrency correctness or fault was tested.
