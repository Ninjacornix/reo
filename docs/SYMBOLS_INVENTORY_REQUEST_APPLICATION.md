A denotes the actor pointer, M=low8 a1 mode, and R the signed-byte helper result. Local actor index is byte 4BADED. For most rows, M=0 admits matching actor byte3 and M=1 admits a different byte3; a failed locality check returns -1. The first four resource-transfer handlers, 5F6800 and 5F6970 additionally require actor class byte2 == 0. The other locality-gated rows admit class 1 directly and apply the identity gate to other classes. Modes beyond 0/1 bypass that identity test; **5F5870's statistics pointer setup only occurs for 0/1**, so a safe general contract for arbitrary modes is not established.

Existing 5F4FE0 remains mapped in [actor resource transitions](SYMBOLS_ACTOR_RESOURCE_TRANSITIONS.md); it is not a new row. Lower instance release, owner acquisition and content exchange contracts are in [resource quantity](SYMBOLS_INVENTORY_QUANTITY.md) and [reservations](SYMBOLS_RESOURCE_RESERVATIONS.md). Lower quantity/use helpers are in [recipes](SYMBOLS_INVENTORY_USE_RECIPES.md), [consumption queries](SYMBOLS_INVENTORY_CONSUMPTION_QUERIES.md), and [auxiliary lists](SYMBOLS_RESOURCE_EFFECTS_AUX_LISTS.md). D92 is an in-game notification bitfield; these mappings do not establish a diagnostics transport or an external network send.

5F5170 arguments are actor, M, one-based prior owner O, first ID F, second ID S. 5B3490 returns 0 immediately without journaling. Result 1 sets actor 54F=3E, then checks 5F29A0 capacity. No capacity optionally releases S's instances when O!=0, but still returns/journals 1; it does not assign owner or insert S. With capacity, only 5B1760(S,A.byte3)==1 permits 5F27B0(A,S) and 5F2330(A), previous-owner detachment and reporting. Result 2 detaches S from its previous owner, publishes F's content through 6DF700 and reports F. Other nonzero recipe results leave the saved result 0 but reach the journal. Thus the journal can accompany an ultimately zero result. For previous-owner detachment, peer BA0 mask 5E4 chooses auxiliary removal 5B6180/5B6300; otherwise it sets A.54F=3E and removes/compacts peer ordinary inventory. Owner indexes are not validated locally.

5F54A0 arguments are actor, M, new ID N, old ID X. Matching current X clears C7C/CA8 and X is detached through 5B1A90 **before** the world/owned exchange admission. R=0/2 requests 67FF80(A,2,N) then returns 0 without D92. R=1 removes X references, optionally clears its claim when 1AFE70()!=0, publishes new content and authority event 20. Finish returns R and writes bit 2/DA2=N/DA3=X except M=1. No inventory insertion of N occurs in this body.

5F5670 arguments are actor, M, O, N. The 5B1760 helper's 0/2 results immediately return 0 without a rejection request or journal. Result 1 detaches former-owner references and publishes N content. Other nonzero helper values would skip that cleanup but still reach reporting and return 1. The current lower helper's actual result set is narrower; no hypothetical extra result is treated as an observed use case. Finish stores bit 1/DA2=N/DA3=O except M=1. Its caller 5F2B70 inserts N afterwards; see [pickup](SYMBOLS_INVENTORY_SPECIAL_CAPACITY_AND_PICKUP.md).

5F5870 arguments are actor, M, O, N, X. Before admission, matching current X is cleared and 5B1A90(X) releases X instances. 5B1DE0 swaps **contents** while preserving each record's owner and self ID; it does not swap the actor slot IDs. R=0/2 requests 67FF80(A,2,N) and exits 0 before journaling. R=1 with O=0 goes directly to finish. Otherwise, when 1AFE70()!=0, peer BA0 mask 5E4 chooses clearing N's claim for O-1, else setting that claim; X is claimed for A.byte3. Mode 1B02D0()==1 subsequently clears both claims unconditionally. The peer's auxiliary/ordinary bank and A's inventory are refreshed, X's content is published, and eligible authority statistics emit events A/B. M=0 uses A for authority, peer category, N for event A and X for B; M=1 uses peer authority, A category, X for A and N for B. Finish preserves R and journals bit 4/DA2=N/DA3=X/DA4=O except M=1. No rollback is present after earlier detach or flag writes.

5F6B90 is reporting only. With O!=0, it indexes the previous actor as O-1 through base 4A5C30/stride10E0; its BA0 is equivalently 4A56F0+10E0*O. BA0 mask 5E4 skips both reports. Authority of A increments half 3B84F0 and sends event B(resource content, previous actor B98). Authority of previous actor increments half 3B84EE and sends event A(content,A.B98). With O==0, authority of A emits event 20(content,0), without these two counters. Return value is unspecified.

5F5D20 and 5F62D0 copy A.A8/AC/B0 into a working XYZ first. Resource inactive or signed quantity <=0 causes actor-slot removal and compaction, then return 0. 5F5D20 additionally clears C7C and refreshes CA8 through 5F1F70. In M=1, if A.room1E2 differs from the local actor's room, 5B1F30 handles use without the parameterized instance path. In that branch 5F5D20 clears current ID for results 1/3, additionally removes/compacts for result 2, returns 0 for result 0, otherwise 1. 5F62D0 removes/compacts for result 2, returns 1 for other results, and performs no current-ID reset. Both cross-room branches skip their normal D92 journal/counter finish.

The ordinary use paths classify signed CD4+BC8: absolute value <= AAB yields BCD=1, otherwise positive yields 0 and nonpositive yields 2. Selector CA8 for current use, or 5B4D50(ID) for content 198, indexes template byte9 at 719A69+44*selector. That byte indexes 24-byte parameter records at 71ABB0. XYZ is first multiplied by the record's float0; Y is then **replaced**, not incremented, by float[1+BCD]. Four signed halves at record+10 are copied as instance parameters. 5F5D20 additionally rotates a local (20,0,0) vector when B99==0, otherwise (10,0,0), by unsigned yaw92 and adds it to an existing instance's 200/204/208 position. 5F62D0 instead creates/binds its resource instance and adds 10 to instance Y before use. These are parameter mutations; the original visual feature names are unresolved.

Then 5B3AA0(ID,&XYZ,&parameters) handles use/decrement. Result 1 invokes 5823E0(A,A+50,&XYZ,ID), plays actor event 1B8C70(A,0) or 1B8BB0(A,10), removes inventory reference and compacts. Result 2 invokes the same effect/sound but retains the slot reference; current use still clears C7C and refreshes CA8. Result 0 skips these actions but still reaches the ordinary finish. M=1 returns 0 without journal. Otherwise authority 1 sets byte 3B84F5=1 and increments word 3B84C4, then journals bit 200 for current or 400 for content 198 and returns 0. These return values must not be promoted into a generic successful-use boolean.

5F6800 also has nontransactional ordering: current-item detach precedes checking the already-set BA4 bit. The BA4 bit is set before checking whether C84/C88 first bytes are empty, and remains set on that -1 path. C88 is inspected and later cleared for every category, but only category B98==6 submits its 32 extra entries. The primary four entries are always submitted when admitted. Counts are narrowed to signed byte; no guarantee of complete transfer follows from the returned count alone.

5B1F30's return classification differs from direct 5B3AA0 use. It clears record flags18 bit40 before activity, quantity and ownership checks. Inactive/depleted sets that bit back and returns 0. An owned, positive record without template bit1 returns 0. With bit1, 5B2590 may already change quantity or content. Only when quantity is still positive and that policy result is nonzero does this wrapper set result1, decrement one for policy1, and optionally destroy a now-depleted record for template40000/result2. A policy result3 overrides final result to3 even if quantity was already reduced to zero by the lower policy. This wrapper does not remove actor inventory references; the callers above do so selectively.
