# Actor action-one priorities, alignment and locomotion candidates

Static File #1 US research, 2026-11-04. Main and overlay identities are recorded
in [the central index](FUNCTION_INDEX.md); original action and substate pointers
are in [actor states](SYMBOLS_ACTOR_STATES.md). No game execution, attachment,
build or replay was performed.

Actor byte +8 is the action index, +9 the substate index, +A an internal phase,
and +B a secondary phase/selector. Numeric labels preserve those different
levels; they are not recovered original action enums. Calling a secondary
handler is not equivalent to calling the full actor update loop.

For the alignment callers, unit interval endpoints 0/1 and tangents 1/0 yield
`w(u) = u + u^2 - u^3` in real arithmetic. That formula describes the mathematical
shape, not a license to reorder guest floating-point operations. It differs from
`3u^2 - 2u^3`. The XYZ path still computes length and normalization, so coincident
positions require a proved admission rule before replacing it with a simpler
host interpolation.

## Primary action-one transition priorities

The following wrappers call transition helpers in a fixed priority order and
stop at the first nonzero result, returning normalized 1; otherwise they return
0. Those callees can consume requests and mutate actor state. This family is
therefore not a set of pure predicates, and calls cannot be reordered or
parallelized just because their result looks boolean.

Unless a row says otherwise, calls are guarded individually by category byte+2
being zero, except 0x64F690, which is called without that local category guard.
The generated-source links retain every branch, argument setup and return path.
The lists below record reviewed ordered calls, not newly inferred callee names.
