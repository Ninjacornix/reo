## Caller and global ownership evidence

First-use calls1264D0, then1264E0 (the reviewed CRI tag1 enter adapter), creates/clears service pools, then1264F8 leaves the guard. This establishes **when**20C7A0 is reset and which subsystem owns that reset. It does not establish the abandoned/unused historical meaning of that word. Nearby ADX downmix control20C7A8 has separate producers/consumers and is not changed by1264D0.

The [Sofdec audio adapters](SYMBOLS_SOFDEC_AUDIO_SERVICE_AND_METADATA.md) provide both counter contexts:164958 calls12A1E8, then12C918, then clears seven words270750;164998 calls12C930, then12A388. Neither counter helper branches on old/new count or invokes another function. The scan finds no independent reader of217D80 beyond these increment/decrement implementations. Calling it a service-client **balance** describes the paired call contract; it is not a proved reference-counted lifetime gate.32-bit ADDIU/SW wrapping and absent lower-bound checks are retained.

The default callback's increment is therefore tied to an observed **original acknowledgement dispatch condition**, rather than inferred from its arbitrary global address. ## Owned-binary, recovered-payload and GP/alias scan scope

Unique read-only [inventory_purpose_gap_owned_refs.py](../tools/function_index/inventory_purpose_gap_owned_refs.py) records the [JSON evidence](../build-function-index/purpose-gap-owned-refs.json). It verifies the resident ELF and all nine owned overlay hashes, scans every file-backed byte region for literal target/global u32 values at **aligned and unaligned** positions, and scans aligned words for direct J/JAL targets. It also follows each LUI's one-register address construction through up to24 subsequent instructions, checking ADDIU/ORI materialization and direct memory operands, stopping when that tracked register is overwritten. All resulting candidates were inspected against the original code and callers. The resulting additional direct-control/pointer inventory contains no hidden function table invoking the five remaining purpose residuals.

Three hash-bound canonical recovery inventories were also scanned: o4 primary63 spans/2605 words, o4 upper53 spans/3966 words and o5 families73 spans/5596 words, totaling **189 spans/12167 reconstructed words**. No literal or direct-control target in those candidates matches these fourteen functions or six investigated globals. The scanner reports candidates, not new graph edges or executed calls, and does not credit an instruction-looking inline datum.

The ELF's original `.reginfo` stores GP=261CF0. All six investigated globals20C7A0,217D80,21C420,224758,224760 and3901E0 lie outside GP's signed16-bit direct addressing window. Therefore a direct memory instruction with that carrier GP cannot hide a reference to them. This says nothing about arbitrary computed aliases, a separately installed GP, runtime-generated pointers, pointers supplied by external code or alias chains longer than the short construction scan. Empty ELF `.symtab` and `.strtab` sections provide no original public symbol identities.

The six globals' admitted direct ownership is exhaustive **within that scan model**:20C7A0 only1264D0's store;217D80 only12C918/930;21C420 only138EA8;224758 only its two clears/two counter helpers;224760 only13F248's store;3901E0 only683AB0's constructed pointer. No negative finding proves whole-program unreachability or absence of an indirect alias. The checked global-store counts are not grounds for a stronger resource/API name.
