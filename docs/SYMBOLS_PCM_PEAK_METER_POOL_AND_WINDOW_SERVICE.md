122AF0 computes a signed integer window using guest CVT.W.S; do not replace this with a host truncation assertion. ZeroN reaches an explicit BREAK7 guard before signed divide. NegativeN is not rejected locally and follows signed arithmetic/loop gates. Requested input byte count is2*(N-consumed). A returned zero/nonpositive halfword count can leave consumed unchanged and repeat the chunk calls; no deadline or iteration cap. Returned chunk count controls the scan, rather than assuming the requested size was supplied. Each halfword is sign-extended before absolute value, so -32768 produces integer32768.

For each channel, frame count initially uses input selector1 availability divided by2 thenN and output selector0 availability divided by10. Signed nonpositive frame count skips processing. The start of every inner scan tests N>0 before taking samples; this is not an unsigned zero-count underflow loop. For a frame's output, GetChunk(0,10,&chunk) is followed by a **literal unconditional self-loop** when returned chunk size==0 at resident PCs122CA8..122CC4. That loop contains NOPs and does not refresh the stack count or call a worker. A positive/nonzero supplied size, not necessarily>=10, proceeds to write the full16-byte record; no local minimum-size admission. This is static liveness/buffer-contract evidence, not a reproduced slowdown.

Output fields are four32-bit words:0=absolute peak,4=starting sample position,8=sample-rate word20,C=N. Input/output stream objects and their vtables are caller-owned. Method return values are mostly ignored. Start122948 resets and zeroes all currently reported selector0 storage on both borrowed stream arrays; it does not allocate PCM output buffers. Peak worker changes first input to selector1 consumption and output to selector1 publication. Pool allocation's channel count has no local upper bound; the record layout holds two pointers at4/8, two atC/10 and two position words14/18 before word1C. A count>2 may overlap subsequent fields, but caller reachability has not been demonstrated.

Only constructor/release enter [optional tag1 critical section](SYMBOLS_NEIGHBORS.md) through1264E0/1264F8. Worker and pool scans do not acquire that guard. Refcount acquire/release are ordinary word operations and can wrap; neither proves initialization is thread-safe. Codec mapping and any native performance cost remain separate.
