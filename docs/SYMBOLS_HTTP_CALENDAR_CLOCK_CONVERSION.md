These are literal static paths; no malformed caller or runtime failure was exercised.

Parser lower-bound admission is incomplete locally: signed upper comparisons alone do not reject month0, day0 or other negative fields if introduced through descriptor state. Month0 indexes the cumulative row at month-1. Numeric descriptor parsing normally supplies decimal nonnegative fields, but absent/partial fields and unusual completed counts must not be normalized to a standard ASN.1 grammar without caller evidence.
