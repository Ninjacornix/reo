All four tables independently match the formula, not merely a sampled prefix. The divisor is split into high16/low16 digits after normalization. Quotient estimates fromDIVU are reduced when their low-digit product exceeds the assembled residual digit; correction branches add back the divisor and can perform a second correction. This is unrolled bounded arithmetic, not a loop that waits for gameplay, GPU work or an external event. A smaller-than-divisor path can return without division.
