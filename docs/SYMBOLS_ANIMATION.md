# Actor animation, frame boundaries and motion descriptors

Static research, 2026-11-04. Original File #1 identities and all overlay instruction checks are in [the central index](FUNCTION_INDEX.md). No target execution, attachment, replay or build.

This separates motion selection, animation-track advancement, pose evaluation and root-motion extraction. They have different side effects. Track callbacks occur per actor and sometimes per track; counting them is not a count of global game updates. The existing clock observer/analyzer remains authoritative for measured gameplay speed.

Original frame-rate mode0x3243CC applies factors1/2 at several different layers. Removing one factor or applying host wall time globally would change the intended game. These mappings identify contracts for future controlled optimization, not a demonstrated cause of cutscene lag.

Two distinct angular encodings are now visible: generic actor angle conversion
uses 65,536 units per turn, while packed animation channels use approximately
16,384 units per turn. Treating all angular values as the same integer format
would change transforms.

Translation-delta helper 0x1925C0 currently samples two complete temporary
matrices and then reads their translation. A future translation-only path is
an optimization **candidate**, contingent on preserving curve-cache mutation,
quantization, input admission and matrix-side effects. No runtime cost or safe
speedup has been demonstrated by this static mapping.

The six curve formats are now a closed static dispatch family. Each sampler
writes a per-channel signed-halfword key cache, and each finder walks from that
cache rather than searching from the beginning. Typical forward playback and
large time jumps may therefore have different costs. Duplicate timestamps,
non-finite times, empty/malformed tables and large counts need explicit
admission rules before any binary-search or compiled-curve replacement.

A candidate compiled descriptor could resolve the format, resource base,
channel destination and key layout once. Any translation-only optimization
must preserve the original cache updates or prove they are unobservable to all
callers. No timing measurement or equivalence replay was run in this pass.
