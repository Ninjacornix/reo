## Static data contracts

- Four peer accumulators:0x815CE0,12 bytes each; halfword0 channel,halfword2 byte count,word4 buffer start,word8 write cursor. Each backing area is172 bytes at0x815A30+172*peer. Outgoing aggregate admission compares against512 bytes.
- Room ownership is128 rows of four owner bytes:0x815830 received,0x815630 comparison,0x815430 authority workspace. FF is an empty slot. Queries distinguish first owner from any owner; two helpers convert absence to different sentinels.
- 0x815D20 is connection state,byte+3 backend queue status,+4 connected,+5 authority,+8 sequence candidate,+28 pending size. These are inferred field roles, not an original recovered C struct.
- Verified file-backed switches:0x8149A0 ten receive targets;0x814970 nine mode7 subtargets;0x8149D0 nine control targets;0x814A60 seven authority-action targets;0x8152F0 thirty-nine log targets. Data values were read from the owned decoded image, not a live process.
