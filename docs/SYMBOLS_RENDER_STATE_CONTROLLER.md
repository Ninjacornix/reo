# Render state controllers, arena checkpoints and graphics block residency

Static File #1 US research, 2026-11-04. Original instruction/source identities
follow the [central index](FUNCTION_INDEX.md). Read with [overlay draw and queue
contracts](SYMBOLS_OVERLAY_MATH.md) and [node palettes](SYMBOLS_NODE_WORKSPACE.md).
No target execution, build, replay, benchmark, network traffic or live attachment.

A callee review corrects the earlier broad interpretation of address19EE90:
it repeatedly removes the head through19EB70 until the graphics block list is
empty. It does not wait for an external worker to make progress. Nodes hold
resource pointer, base, span and alignment; state4 is written on eviction, but
its exact SDK enumeration remains unresolved. These static operations do not
establish a measured slowdown or a safe allocator/rendering replacement.
