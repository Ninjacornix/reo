The transport compaction helper caps its read-ahead limit to full capacity without subtracting an append prefix. It does not independently admit positive arguments, prefix-plus-read capacity, or child return counts. These are local contract boundaries, not demonstrated overflows. Compaction uses resident `107AB0`; overlap behavior is delegated.

`7234A0` accepts an alert only with exactly two remaining bytes and zero record offset. It notifies connection/parent info and alert callbacks, event `4004`, with combined severity/description. Warning level 1 records description in workspace `104`; description zero sets received-shutdown and returns zero, other warnings discard and continue. Fatal level 2 records description in `108`, logs it, sets received-shutdown, removes cached session and returns zero. Other severities fail with fatal alert `2F`.

ChangeCipherSpec type `14` must contain exactly one byte equal to 1 with zero offset; it consumes the record, sets workspace `100`, calls `723C30` and resumes reading on success. Unexpected handshake type `16` outside nesting can select states `11D0` or `2000`, invoke the handshake callback, and return -1 after marking the BIO for retry. Unexpected application type `17` is admitted only through the explicit workspace `120/118` and handshake-state windows `1110..1120` or `2110..2120`; otherwise it fails. Unknown record types are skipped for version `301`, and rejected for the other admitted version. These paths and the zero-length-record loop have no local iteration budget. No claim is made that malformed-input or repeated-record cases occur in gameplay.
