# Kernel entry mapping: exact wrappers and SDK ABI cross-check

Static investigation, 2026-11-03. Adds 140 API-family candidates from the owned
File #1 main ELF. These are actual kernel entry wrappers, not guesses based on
an address range. They complement the gameplay and rendering investigations.

Target: SLUS-20765, SHA-256
`06bd5fd7243144cd30cdd0c0023763a369738cb91b177b35e85f6a4782b4ca46`.
No game, build, live process read or debugger attachment was performed.

## Admission and confidence

Every row below passed an exact original-byte rule: aligned catalogue interval
of 16..32 bytes, first instruction ADDIU v1,zero,signed16, followed by SYSCALL 0,
JR ra, NOP, with only zero padding after that. The identity-checked ELF supplies
all four words, including omitted NOP comments. Source links use the catalogue's
source owner, including shared generated files. Numbers retain their sign.

The operation name is an ABI candidate from PS2SDK, not proof that every kernel
revision or the host implementation implements the full same API. In particular,
SDK RFU entries and unmatched numeric selectors were excluded from the reviewed
count. Ambiguous AddIntcHandler/AddDmacHandler variants share a family label;
identical wrappers do not determine the caller's extra-argument contract.

Reference: [PS2SDK syscall numbers](https://raw.githubusercontent.com/ps2dev/ps2sdk/af212628b7a3b4f7197675c7236d6bec849c883b/ee/kernel/include/syscallnr.h), revision `af212628b7a3b4f7197675c7236d6bec849c883b`, source SHA-256
`573f0c3276eaae064f0da04990126133b434259b3b235e53ed8f013694300edc`. The [SDK assembly wrapper definition](https://github.com/ps2dev/ps2sdk/blob/af212628b7a3b4f7197675c7236d6bec849c883b/ee/kernel/src/kernel.S)
provides the corresponding v1/syscall/return convention. Only identifier/number
facts are incorporated here; SDK code and game bytes are not copied into the
repository. Existing local runtime routing is compared separately below.
