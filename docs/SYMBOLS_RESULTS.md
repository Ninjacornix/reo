Static File #1 US research, 2026-11-04. Catalogue partition **o9**, runtime id **9**, loadbase0x810000, owned MWo3 name `single.bin`. This partition contains result UI and gameplay/local-message code; its functions must not all be called result handlers. Identity and instruction comparison are in [the central index](FUNCTION_INDEX.md). No game, network session, live-memory read, attachment, build, replay or benchmark occurred.

The result-context pointer lives at0x893800. It is assigned a separate preallocated buffer;0x893800 is not the context allocation itself. Text resources use XOR-FF decoding into context-owned scratch, while pictures use registered ids0x2600..2605. Callback registration, drawing, input state and cleanup are separate boundaries.

The local-message family resembles [o8 networking](SYMBOLS_NETWORK_EVENTS.md) but is a **different implementation**. It sets connected/authority flags itself, uses local256-byte packet slots, and advances a float byone per service invocation. No external handshake or network send was inferred. Queue limits and owner restrictions differ, so replacing it with the o8 contracts would be incorrect.
