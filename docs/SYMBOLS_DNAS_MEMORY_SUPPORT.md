A managed buffer cell has **pointer +0, byte size +4, optional cleanup callback +8**. Provider size queries feed its resize helper; the temporary query result is a size, not a preallocated provider-state pointer. Owned-allocation tracking uses **count +0, capacity +4, twelve-byte record array +8**; each record has pointer/size/custom-release at +0/+4/+8.

The wrapper **0x6F9B58 explicitly frees the old allocation when its resize call returns NULL**. It also converts requested size0 to1. A host replacement must preserve this ownership contract rather than assume the standard C realloc failure contract. This is verified wrapper behavior, not a reported runtime bug.
