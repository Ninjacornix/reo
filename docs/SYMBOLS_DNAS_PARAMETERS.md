# DNAS overlay: parameter descriptors, factories and owned allocations

Static File #1 US research, 2026-11-04. Catalogue **o5**, runtime MWo3 id **7**, base **0x6E0000**, owned name **insdnas.bin**, SHA-256 **97174f5d367cd90bedd5ba397c6492e9fb4bbd0ec7d6021c2be524c49925d38e**. Continues [cipher objects](SYMBOLS_DNAS_CIPHER_OBJECTS.md) and [whole-message padding](SYMBOLS_DNAS_PADDED_BLOCKS.md). Descriptive roles below do not recover original algorithm names, runtime provider selections or replacement implementations. No game, build, replay, network request, live-memory read, attachment or benchmark occurred.

This family registers **descriptor identity pointer / payload pointer** pairs in a counted eight-byte array: count **+C**, array pointer **+10**. A lookup matches identity by pointer equality. Separate allocation records track memory created for payloads and arrays. Descriptor exporters below return exact guest pointers, often into adjacent structures sharing callbacks. Returning different pointers does not establish a different cryptographic primitive.

The common registration entry 0x6ED6B0 appends a new pair; it does not replace or deduplicate existing identities. Common lookup 0x6ED748 returns the **first** matching pair. These distinctions matter before recreating the original configuration API. Parameter words are retained as numeric fields and bounds when original meanings are unknown.
