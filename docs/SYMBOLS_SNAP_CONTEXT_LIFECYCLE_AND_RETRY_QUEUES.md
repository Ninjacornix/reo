The constructor's option vector is NULL-terminated. Owned strings257CC8=`INITIAL_LATENCY` and257CD8=`MAX_RETRIES` select following decimal values; an unrecognized entry advances the index twice. Missing value bounds are not checked here. Initial latency22 is copied to510 after parsing. A single global context is published with no existing-handle admission check in this constructor.

Binding retries increment a sixteen-bit port and retry on every negative backend result. The constructor does not distinguish address-in-use from other errors and has no failure ceiling. That is a concrete dependency for later analysis, not evidence the loop ran or caused any captured hitch. The recurring retry sweep is also separate from socket transmission: it only moves packet ownership between lists.

The entire static allocator and all its users share an arena reset lifetime. Calls that create another context or tear down while borrowed pointers remain live need a caller proof. No such conflicting call sequence was observed or tested.
