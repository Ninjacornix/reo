The actor loader combines file reads, halfword-LZ texture decompression, registry ownership, resource-heap compaction and model construction. These operations have separate identities and may contribute different costs.18DCB0 is already mapped as quiesce/compact/relocate; calling it is a synchronization boundary, not proof that it is responsible for the observed cutscene lag. Invocation frequency, actual asset counts and matching native override selection remain unknown.

1AAD20's literal7 check governs a trailing sentinel after all texture records; it does not limit the loop to seven records. Source records, texture counts and output extents remain caller/data contracts. The constructors do not perform transactional rollback when an earlier delegate fails. No engine fix or runtime safety claim follows from these findings.
