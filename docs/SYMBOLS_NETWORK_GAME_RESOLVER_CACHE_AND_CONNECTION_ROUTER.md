The resolver cache stores256-byte bounded/padded names and a four-byte address in each260-byte record; an exactly full name need not have a terminator, though comparisons are bounded. Query phase does not use its caller countdown to enforce a deadline. Its return values1/0/-1 mean completed/pending/failure at this layer rather than byte counts or elapsed progress.
