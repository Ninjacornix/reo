# Resident host/DVD filesystem configuration

Static File #1 US research, 2026-11-04. [Owned identities](FUNCTION_INDEX.md). No game, build, replay, live attachment or timing measurement.

Owned strings identify HOST/DVD setup, directory filenames and optical path conventions. Calls into CRI backend adapters are described by their observed argument routing; original API spellings are not assumed. These functions configure shared state used by later file operations, rather than providing evidence that a room load was slow.
