## Evidence and limits

All **35 mapping rows / 3,569 unique-PC instruction comments** in this notebook were compared, within their catalogue intervals, with owned decoded o9 bytes; no conflicts were found. The aggregate o9 audit covers **328 code entries / 22,941 instruction comments** across the results and single-player notebooks, with no conflicting owned words. Binary identity is SHA-256 **604126d6edca1b1333948d79d1d2c8d2f2e22f4a233efbdfb769c106dafe7343**. This checks instruction identity, not proof of every descriptive hypothesis. Exact pointer arrays at 0x8294C0, 0x82B450 and 0x82B480 were read from that same image. The twelve observation reaction routes at 0x82B450 are `812AB0, 81289C, 8128CC, 812AB0, 812950, 8129C8, 812AB0, 812AB0, 812A30, 8128B4, 8128B4, 812AB0`; these are internal branches of 0x812540, not twelve new entry functions.

Potential static edge cases are preserved rather than silently repaired: negative profile index admission, the unbounded immediate goal redispatch, FF-terminated scans without local length caps, and 0x815BC0's reverse-fallback return/store difference. Establishing reachability, correctness expectations, or performance consequences requires caller/data validation and later controlled testing. This notebook performs none of that runtime work.
