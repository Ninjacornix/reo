# Native transfer group membership

32 live DTR children and one shared8-child DTX owner, composed with the existing
native audio dispatcher. DTR service tails into DTX; the outer DTX boundary uses
that same owner a second time. Individual transfer protocols remain separate.

See the [contract](../../../docs/native-media/ADXT_TRANSFER_GROUPS_CONTRACT.md)
and [evidence](../../../docs/native-media/ADXT_TRANSFER_GROUPS_IMPLEMENTATION.md).
The frozen original inputs predate `transfer_groups.cpp`. No production selector,
device, game, dependency library or compatibility path changed.
