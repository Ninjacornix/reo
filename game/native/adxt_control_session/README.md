atomic enrollment, explicit mix order and retained retirement. This replaces

See the [contract](../../../docs/native-media/ADXT_CONTROL_SESSION_CONTRACT.md)
and [evidence](../../../docs/native-media/ADXT_CONTROL_SESSION_IMPLEMENTATION.md).
