# ADXT playback control

Independent buffering/start/drain owner and concrete phased PCM storage bridge.
No runtime, game window, guest ABI, device or global clock is required.

See the [contract](../../../docs/native-media/ADXT_PLAYBACK_CONTROL_CONTRACT.md)
and [qualification](../../../docs/native-media/ADXT_PLAYBACK_CONTROL_IMPLEMENTATION.md).
Original inputs and330 executed transcripts are local evidence. The checked-in
manifest pins the exact source, and verify.py compares318 admitted clients on
an exact compiler;12 uneven-channel states are explicit exclusions.

Select the standalone CMake target `adxt_playback_tests`, or build the parent
`game/native` project. This is not yet a complete Window2/output composition.
